## 职责与原入口

`build_image_param_fields` 与 `/api/image-params` 的完整主体归入现有 `backend/image_provider_service.py`，负责图片供应商参数字段和引擎选择；main 保留原函数签名、默认值与 FastAPI 装饰器，只做委托。原单行请求模式适配已经归属供应商配置模块，本批未重复迁移。

参数目录使用的比例、分辨率和参考图上限仍作为应用声明值显式传入；供应商目录加载与协议判断均为显式回调。接管模块不自行读取配置、凭据或访问网络。两个完整主体（含查找供应商的生成器）语法树一致；main 和接管模块的其他语法树不变，也没有新增后端导入边。

保留 API 的 GPT Image 2 自动尺寸、各引擎质量选项、数量/参考图字段、默认值与选项顺序，以及 RunningHub 原动态字段提示。既有回调仍在调用时从 main 传入，原测试或运行时替换回调的行为保持。

检索未发现两画布脚本直接调用 `/api/image-params`；两画布目前加载共享 `canvas-image-params.js` 并使用各自节点参数适配。保留已注册的公开后端接口。下述接口 HTTP 证据与双画布浏览器回归分别报告，浏览器回归不作为“画布实际调用该接口”的证据。
