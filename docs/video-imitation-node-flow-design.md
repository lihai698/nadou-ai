# 视频模仿制作：分镜直连图片与视频

日期：2026-10-21。状态：用户已验收。真实模型的成片效果未验证。

## 分镜表与创建入口

分镜表右上角保留一个“创建所选镜头节点”按钮。勾选镜头后，每镜只创建图片与视频两个原生节点，连接为“分镜表 → 图片 → 视频”。图片提示词直接写入图片节点自身的生成栏，不另建独立提示词节点。创建动作不提交生成任务，不再先弹出模型配置表。

两种画布每镜均新建两个原生节点。普通画布为分镜表 → generator → video，图片和视频结果显示在原节点内；智能画布为分镜表 → smart-image（图片）→ smart-image（视频）。模型与参数仍在各自原生工具栏中选择。

## 两类提示词分别使用

- 分镜图片提示词：沿用 imagePrompt 字段，缺失时读取画面列；直接进入图片节点自身的可编辑生成栏，仅用于图片生成。
- 分镜视频提示词：沿用 motionPrompt 字段，缺失时读取运镜列；直接填入视频节点的可编辑提示词，配合本镜图片用于视频生成。
- 列表与逐镜编辑器均显示这两个名称。视频请求不能拼入图片提示词，图片请求也不拼入视频提示词。
- 修改表内提示词会同步尚未单独修改的对应节点；节点里的手写内容保留。存在未完成或待查询任务时，先处理原任务再修改对应输入。

## 内置视频拆镜规范

实际模型指令在 `backend/canvas_video_analysis_prompt.txt`，两种画布共用，不需要另外安装 Codex skill。图片提示词还原本镜起始关键帧，分别描述主体姿态、场景空间、构图视角、光色材质和画风；视频提示词分别描述时长与起始状态、动作时序、运镜过程、结束画面和连续性。运镜列只记客观镜头变化，编辑它不覆盖完整视频提示词。旧行缺少视频提示词时仍可读取运镜列，避免旧画布失去输入。

本地分析每镜按时间顺序抽九帧（片段的 2% 至 98%），发送真实采样时刻，原片对照图使用首个采样帧。自启本地模型上下文设为 8192，分析输出预算为 2800 tokens；复用用户已启动的模型服务时不改其启动参数。云端保持原有三帧与一次确认调用，不增加云调用。采样不能保证发现所有短暂动作、淡入淡出或切点，不能把检测到的一段强说成连续镜头，也不能仅凭时长增加分镜。

对白来自独立语音转写；视觉模型不得编对白或看不清的屏幕文字。已有表格及手改提示词不会随代码更新自动重写，需要重新拆解或重新分析本镜才能得到新版分析。后端源码变更需重启 Nadou 主程序后加载。

## 兼容现有作品

重复创建复用已有制作链，不重复新建。已有输出节点、第二个提示词节点和结果保留；未手改的旧合并提示词可以原位拆分为图片与视频各自的内容。用户改过的提示词不覆盖。

部分删除、断线、只读画布、分析未结束、保存失败或切换画布均有明确提示。一次创建使用一个撤销记录；保存成功后定位制作链。保存失败后再次点击复用内存中的节点。

普通画布内嵌视频任务仍保存原任务编号和待查询卡片，刷新继续查询原任务；未完成时阻止重复提交。智能画布沿用已有任务恢复，重新生成图片得到新结果分支时更新本镜视频参考图；失败回退原绑定。

## 创作与成片

1. 核对分析得到的镜头顺序、构图、动作、对白和时长，修改人物、商品、场景及两类提示词。
2. 勾选镜头并创建图片、视频节点。先选择图片模型生成画面，必要时连接同一人物或商品参考图保持一致性。
3. 在视频节点核对视频提示词，选择视频模型，使用本镜图片生成视频。目标时长与模型支持的实际生成时长分别保留。
4. 已完成视频可在分镜编辑面板底部“整理所选视频”。普通画布加入原生剪辑时间线，智能画布加入原生视频分组；现有剪辑与下载能力保持，不把分组宣称为自动成片。

助手的严格 materializeRows 图片转换入口保持原有模型校验和确认权限，不从界面创建图片、视频节点推断助手拥有视频执行权限。
