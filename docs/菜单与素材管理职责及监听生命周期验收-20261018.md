| 模块 | 职责 | 状态所有者与接入 |

当前管理页没有旧 `gateAssetManagerBtn`，但普通编辑器 HTML 仍包含素材管理弹窗和关闭入口。原 gate 监听与公开函数继续兼容旧模板，不恢复正式界面的旧按钮。移除条件是确认旧模板/外部入口不再使用或用户明确要求移除；不把缺少当前可见打开按钮误报为已删除全部兼容入口。

## 事件生命周期

- 三个 `create(host)` 控制器只有显式 `mount()` 才绑定。重复 mount 不重复注册。
- pagehide 解除本批绑定；pageshow 恢复一次。dispose 解除组件监听和两个生命周期监听，此实例之后不再恢复。
- 素材管理的 modal click 保持原 `true` 捕获选项；tab click、modal change、普通 document 事件、智能菜单事件保持原注册顺序和选项。
- 两个动态上传 input 的 change 监听由素材管理控制器保存；重绘前清除旧输入监听，离页解除，恢复重绑，dispose 清空。上传回调里的业务请求、响应和状态处理保持原样。
- 普通自建连线、输入、输出、图片菜单中的动态按钮 onclick 在 pagehide/dispose 时解除，并关闭相关菜单。这个清理只改变临时菜单和连线菜单状态，不改 nodes、connections、素材或保存数据；回到页面后菜单保持关闭，重新打开才生成新动作。
- 静态 HTML 的 inline 入口仍由原模板和公开函数负责。本批不据此声称全项目所有事件已被统一托管；其余编辑器、快捷键、选择、刀切及媒体等监听仍需继续审计。
