# 普通画布完整创作同步（2026-10-12）

用户明确要求将智能画布的完整创作工作流同步至普通画布。本次在原有 `create_story_workflow` 工具内适配，不创建另一套助手或页面。

## 实现

- 共用故事、剧情逐字来源、资产及声音引用、剧情覆盖和整批原子校验。
- 普通画布使用原生 `prompt`、`shot-table` 和逐镜 `prompt → generator → output`；智能画布保持原生类型。
- 六份创作文档、正文与资产到分镜表、分镜表到逐镜提示词的来源连线均保存。来源线标为 `story`，不混入图片生成输入；提示词与生成/输出连线负责实际生成。
- 普通配图复用现有节点构建器，保留手选平台、模型、比例、分辨率、质量及自定义尺寸。
- 助手局部修改逐镜提示词时，原子同步表行和结构化镜头记录；普通生成节点通过原提示词输入线读取新内容。生成忙碌或链丢失时拒绝修改。
- 原生分镜表编辑也支持文本故事链同步，失效旧工作流内容摘要，避免编辑后被错误复用。已有模型、图片和另一镜内容保留。
- 普通画布新增原生连接点，重开清理和复制保留合法来源线；仍清理悬空/无归属来源线。

## 使用与边界

双击 `run.bat`，打开普通画布 → 创作助手，手动勾选文本、图片模型，再要求“创作故事并拆解剧情、角色、场景、道具、声音设计，创建完整分镜表和逐镜配图节点”。已有正文也可指定作为来源。

配图是待生成节点，声音是设计稿；真实模型内容质量和供应商出图未由本次模拟验证。收费媒体仍按现有方案确认执行。未删除旧原生入口、用户画布或素材，未提交/上传/发布；待用户手动确认后选择性同步源码。
