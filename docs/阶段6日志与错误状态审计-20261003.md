# 阶段 6：日志与错误状态首轮审计

日期：2026-10-03  
范围：公开代码中的网络诊断日志、外部请求失败处理和任务错误状态。审计使用隔离测试，不读取 `API/.env`、用户数据，也不调用真实供应商。

## 已修复

`main.py` 原来的 `log_net_error` 会把请求 URL、系统代理字典和异常链原文输出到控制台。URL 查询参数可能包含令牌，代理 URL 可能包含用户名和密码，异常文本也可能重复这些内容。`httpx_request_with_transient_retries` 的重试日志同样直接输出完整 URL 和异常。

本次加入三个小型脱敏函数并接入上述两个真实入口：

- URL 日志仅保留协议、主机、端口和路径，移除用户信息、查询参数和片段。
- 系统代理日志仅保留代理类型及脱敏后的主机、端口和路径，跳过 `no_proxy` 内容。
- 异常链和上下文会移除 URL 查询值，并遮盖 `api_key`、`token`、`secret`、`password`、`authorization` 等常见赋值内容。
- 网络错误和重试日志中的上下文、异常及 URL 设有单条长度上限，避免单个上游回包拖大控制台输出。

保留主机、路径、错误类型和重试次数，便于判断请求目标和线路问题；脱敏失败不会阻断主流程。
