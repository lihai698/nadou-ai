# 长音频、立体声与大文件验收

本次普通画布与智能画布均通过10分钟、30分钟双声道MP3和接近100MB的WAV上传、播放器操作、下载和保存重开验收。修复智能音频无波形时播放器过窄，以及超限/上传失败提示异常。仍待用户手动确认本次修复；未提交、上传或发布。

## 使用与后续

原程序双击`run.bat`，进入普通或智能画布，刷新页面后上传音频即可。单文件限制仍为100MiB，批次500MiB；大文件省略波形时仍可使用播放器。
