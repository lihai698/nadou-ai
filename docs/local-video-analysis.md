# 本地视频分镜分析

普通画布与智能画布共用视频拆解逻辑。视频编辑中的「拆成镜头表」直接创建表格并开始本地分析，进度在表头显示。拖动表头可以移动节点；逐镜「编辑」保留手工编辑入口。

视觉分析先检测切点，再按每镜首、中、尾抽取三帧；这不是逐帧理解整段视频。对白单独使用本地 Whisper 转写，不根据画面猜测。没有人声时对白为空。

系统指令在 `backend/canvas_video_analysis_prompt.txt`，修改后重启程序生效。保留要求的 JSON 字段名，前端才能接收分析结果。

本机配置保存于被 Git 忽略的 `data/local_video_vision.json`，包含 `executable`、`model`、`projector` 三个绝对文件路径。直接复用已有 llama.cpp、GGUF 与匹配的视觉投影文件，不复制大模型，不把个人路径写入源码。其他电脑需配置自己的文件路径。

本功能连接回环地址 `127.0.0.1:8085`。没有现成服务时，使用本机配置启动 llama-server；最后一个分析任务完成后关闭本功能启动的进程。复用用户自己启动的服务时不会关闭该服务。模型加载或分析失败会显示错误，不自动切换云端。

本地语音组件下载使用固定版本、大小和 SHA-256 校验，主地址不可达时尝试清单内备用地址。所有地址都必须通过原有校验；失败或取消时保留原安装。分镜表逐镜编辑面板提供失败后的组件修复入口，安装后可重试本地对白。

Windows 语音引擎在其运行目录内使用相对文件参数，避免中文项目路径造成崩溃；原素材地址与画布位置不变。

后端源码改动后需要重新启动主程序；浏览器刷新仅加载前端资源。

启动脚本检测到已有 Nadou 后台时会复用该进程，单独再次双击 `run.bat` 不会更新已加载的代码。先停止原后台，再运行脚本。前端在提交本地分析前检查后台能力；版本未更新时在表格中明确显示重启说明，不提交停留在旧确认流程的任务。
