## 职责与真实入口

- `backend/canvas_asset_export_service.py` 拥有素材 ZIP 下载、智能分组文件导出和导出目录创建。
- `main.py` 保留两个 POST 路由、请求模型和三个薄转发函数；本批只修改三个函数及新增一个模块导入。
- 依赖方向为入口 → 导出服务 → 既有 `canvas_asset_rules`；服务不反向导入 main。
- 当前存储根目录、本地解析、同名本地回退及远程读取由入口传入；新服务不读取配置或素材索引，不修改画布状态。
- 原业务主体已从入口删除，只保留一个实际实现。原有 ZIP/重名/文本命名、处理数量上限和错误语义保持不变；删除了迁移主体中未使用的 MIME 初始化变量。
- 普通画布输出菜单、普通分组和智能画布批量下载均调用 `/api/canvas-assets/download`；素材管理也使用此接口。
- `/api/smart-canvas/group-export` 的后端合同保留，本次全局搜索未发现当前前端调用方；不因当前无页面调用而删除公开接口。
