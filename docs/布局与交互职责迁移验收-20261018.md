# 布局与交互职责迁移验收

## 实现范围

普通19项、智能32项，共51函数迁入 canvas-layout.js、canvas-interaction.js、smart-layout.js、smart-selection.js。真实页面按序加载，原函数只转发。未保留原函数体副本。

布局模块负责屏幕坐标、节点矩形、媒体自然/显式尺寸、分组与连通图排列；交互模块负责普通框选/节点拖拽/缩放/连线拖拽及松手清理；智能选择模块负责选择状态和DOM选择同步。宿主经getter/setter提供实时选择、视口与拖拽状态，并提供渲染/保存/撤销回调。智能主鼠标事件处理器、视口缩放/小地图和剩余渲染仍在入口。

同模块函数被作为事件回调使用时，显式绑定deps后转发所有实参；已检查相关函数不使用回调this。递归移动继续传递seen集合，防止共享成员被移动多次。
