# 普通画布旧生成入口清理验收

本批基线为 `732b0f850eb0f5c5821053d49129b516dfe21dc6`，范围只包括普通画布旧生成主体清理、必要知识来源摘要和本文。整体模块化仍未完成，不发布、打标签或制作安装包。

## 改动与职责

- 删除 `static/js/canvas.js` 中没有仓库调用方的 `runGeneratorLegacy`。全仓库搜索只发现定义和描述以前状态的历史文档，未发现调用、导出、配置引用或声明的兼容职责；本批明确清理它，不继续保留两套图片生成主体。
- 保留真实入口 `runGenerator`，仍由 `classicGenerationHost()` 向 `CanvasMediaRunner.runGenerator` 提供当前状态和依赖。按钮入口继续经过 `runCanvasGenerate` 和 `CanvasCascadeRunner`，循环、助手和任务恢复调用保持原状。
- 删除只覆盖旧函数的完整连续代码段。其余已提交源码保持逐字节一致；未删除仍被其他生成器和任务流程使用的公共工具，也未删除其他页面仍使用的 `/api/online-image` 后端接口。
- 知识索引中 420 个指向 `static/js/canvas.js` 的来源摘要必须随该文件变化，已统一更新；递归 JSON 对照确认只有这些摘要发生变化，功能、参数、来源路径等字段未改。
- 普通画布文件中的清空菜单收起、镜头表拖拽判断属于并行窗口，位于其他代码段；本批精确删除时保留它们，提交只使用基线加本批的固定候选，不混入并行改动。

## 验证

- 删除前后在隔离公开代码副本上运行同一组 142 项现有测试，均通过：普通生成模块、原生助手、生成输入、任务提交与轮询、受理恢复、智能生成及未知任务重查。没有为删除增加重复实现断言或修改既有测试。
- 基线与候选的真实 Chrome 页面都通过同一验收链。普通画布实际点击生成按钮，恰好提交一次模拟图片任务，使用当前提示词与所选模型，随后查询原任务、回填图片并实际保存；刷新后结果仍存在。候选全局旧函数为 undefined，现行入口仍调用 CanvasMediaRunner。
- 普通输出图片等待解码成功，截图核对图片实际可见；没有只检查节点数据就宣称画面已显示。
- 智能画布没有该旧函数，产品源码未修改。关联验证实际点击智能提示词运行按钮，检查模拟文本结果回填、保存和刷新重开，确保另一画布的生成与保存入口仍可工作。
- 浏览器测试只模拟图片任务提交/查询和 LLM 响应，其余画布读写走隔离临时服务；服务导入前显式固定 sys.path，断言 main.__file__、BASE_DIR、DATA_DIR、素材和输出目录均在临时目录。未读取用户配置、画布或素材，未调用真实供应商或收费服务。
- 固定候选完整核心检查退出 0：Python 1209 项、JavaScript 1118 项；所有 JavaScript 语法及中英文词条与页面引用检查通过。该结果只认证固定候选，不覆盖并行窗口进行中的混合修改。
