# 视口与小地图迁移验收

## 实现范围

普通22项、智能9项，共31函数迁入 canvas-viewport.js 与 smart-viewport.js，真实HTML按序加载，原入口保留委托。负责视口变换、小地图投影/定位、总览进入/退出/节点居中，以及普通会话视口存取和动画帧刷新调度。

宿主提供当前视口与小地图状态getter/setter、DOM引用、浏览器CSS/sessionStorage对象，以及既有渲染和保存回调。普通会话位置与智能画布保存的原有差异保持，没有合并两种保存路径。窗口事件绑定本轮保留主入口。
