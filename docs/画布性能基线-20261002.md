# 画布性能基线（2026-10-02）

本记录接续聊天记录末尾中断的浏览器测量。已取得加载事件、完整可交互时间、真实自动保存、拖动/缩放/框选功能、普通输出原生拖放、短时空闲内存和短时拖动帧率记录；长期内存趋势尚未测量，阶段3保持进行中。

## 环境与方法

- Windows 10、Python 3.10.11，Codex内置浏览器，视口815×612；只访问127.0.0.1:3002隔离服务。
- Git基点53168d8，工作区已有未提交修改。隔离main.py、canvas.js、smart-canvas.js与工作区对应文件SHA256相同。实际脚本哈希见本轮验证证据。
- 普通/智能各10、100节点，文字与图片各半；图片重复引用同一张320×240、1232字节PNG。普通无连线，智能分别5、50条连线。不能代表大量不同高清素材或高并发生成。
- 每组禁用缓存3次、正常缓存3次，共24次；同一浏览器进程，没有重启进程或清空操作系统缓存，所以“禁用缓存”不称为冷启动。上个窗口HTTP读写记录独立保留，不与本轮浏览器时间混合。
- 页面导航后等待最后一个样例节点进入DOM，再读取CDP Performance指标。DOMContentLoaded表示页面结构加载事件；节点采样时间包含自动化观察延迟，只是节点已出现的观察上界，不是精确可交互时间。
- 最初预采样在节点出现前读取，已排除，未进入正式24次记录。屏外图片存在延迟加载，未把全部节点存在误认为全部图片加载完成。

| 类型/节点数 | 编辑工具调用开始至请求发出，中位数 | 请求发出至响应下载完成，中位数 |

| 普通100 | 529 | 19.50 |

前一列包含自动化调用延迟及页面自动保存等待，不能解释为后端耗时；后一列用CDP单调时钟计算，包含本地网络及服务处理。智能100节点单次最大72.37毫秒，原始数据完整保留，不删离群值。详见[自动保存证据](evidence/20261002/performance-autosave.json)。

页面保存会按现有逻辑补齐节点默认字段，因此只确认节点/连线数量和提示词恢复，不声称整个JSON逐字节不变。早先[HTTP基线](evidence/20261002/performance-http.json)中的内容一致结论仅对应当时接口读写测试。

## 完整可交互时间与拖动帧率

本节使用同一浏览器、同一隔离服务和固定样例补测。完整可交互时间从导航开始计时，直到预期节点全部进入 DOM、至少一半节点编辑控件存在，且当前视口内图片均已完成加载；这比单纯 DOMContentLoaded 或 load 更接近用户可以操作的时点。四组各 3 次，全部满足条件且没有超时。

| 样例 | 可交互时间中位数（毫秒） | 三次范围（毫秒） | DOMContentLoaded 中位数（毫秒） | load 中位数（毫秒） |
| --- | ---: | ---: | ---: | ---: |
| 普通10 | 465.3 | 435.0～717.0 | 271.6 | 311.9 |
| 普通100 | 625.9 | 603.2～642.7 | 241.0 | 280.0 |
| 智能10 | 537.6 | 415.0～614.8 | 166.2 | 177.6 |
| 智能100 | 666.1 | 657.2～692.6 | 185.5 | 196.1 |

随后对四组样例各执行 3 次真实鼠标拖动，采集约 1.1 秒的 `requestAnimationFrame` 时间戳并把节点拖回原位。普通10、智能10、智能100的 9 次窗口均接近 60Hz；普通100的 3 次窗口分别出现 2、3、2 个超过 20ms 的帧间隔，最大间隔 83.4ms。中位帧间隔仍为约 16.7ms，因此这里只记录固定视口下的短时观察，不把它解释成长期稳定的 60FPS 承诺。

原始读数见[完整可交互与帧率证据](evidence/20261002/performance-readiness.json)。测量期间只使用临时页面级帧采集器，没有修改业务代码；每次拖动随后反向拖回，隔离服务生成调用数保持为 0。

### 短时内存观察

同一标签页依次打开普通0/10/100、智能0/10/100节点。节点出现后自然空闲5秒，间隔2秒采样3次。当前浏览器接口不支持强制垃圾回收，因此不强制回收，不将自然GC或跨导航保留对象造成的差异解释为节点独占内存。

| 样例 | JSHeapUsedSize，三次读数范围（MiB） |
| --- | ---: |
| 普通空画布 | 25.23～25.23 |
| 普通10 | 25.38～25.38 |
| 普通100 | 25.53～25.54 |
| 智能空画布 | 22.15～22.16 |
| 智能10 | 21.95～21.95 |
| 智能100 | 22.08～22.08 |

同期独立采样隔离后端36次，间隔2秒：工作集59.13～60.15MiB，中位60.02MiB；私有内存52.23～53.07MiB，中位52.86MiB。浏览器指标是JS堆，不是浏览器全部进程内存；后端采样覆盖测量期间整体，不按单个画布归因。原始记录为[浏览器内存](evidence/20261002/performance-browser-memory.json)和[后端内存](evidence/20261002/performance-backend-memory.json)。

这些数据仅表明短时空闲窗口读数较稳定，不证明长期无泄漏，也不覆盖生成、视频、高清素材或频繁开关画布的压力。后续需要这些场景时再专门测量，不以扩大测试规模替代真实需求。

本次无业务实现替换、删除或新增依赖，只更新验收材料。普通输出素材回存的原生拖放已在隔离页面完成，证据见[evidence/20261002/native-output-drag.json](evidence/20261002/native-output-drag.json)。阶段3剩余未覆盖项为长期资源趋势，以及核心流程清单中仍标记待测的非性能场景。
