# RunningHub 标准 OpenAPI 迁移验收

2026-10-18。本轮将标准接口图像、视频生成链路移入 backend/runninghub_openapi.py，并扩展现有 runninghub_protocol.py 的参数纯规则。main.py 从22,369行降为22,062行，净减少307行。三个大文件整体模块化仍未完成。

## 职责与依赖

- runninghub_protocol：schema选择、默认值转换、尺寸/比例/分辨率、图生视频判断，共8项迁入的纯函数；复用原状态和任务编号解析。
- RunningHubOpenAPIAdapter：结果解析、参考文件上传、图像提交/轮询、视频提交/轮询和输出保存协调，共6个执行方法。
- main：标准图像/视频入口委托适配器；模型目录、配置/认证、素材访问和下载保存函数通过依赖注入提供。应用/工作流模式保留原分支。
- 新模块不导入main/FastAPI，不拥有另一套任务存储、供应商配置或密钥。领域错误在main转换为原HTTP状态与详情。
- 删除迁出的原函数体。尺寸/分辨率包装及schema_value导入仍被应用/工作流模式使用，保留这些共享入口有实际调用依据。

## 保持的行为

上传multipart字段、请求头、参考图数量上限、首尾帧角色、参数默认值和超时不变；图像/视频的任务编号受理回调仍先于轮询；直接结果不额外提交；原HTTP错误与未知回包处理保持。没有新增自动重试或供应商功能。
