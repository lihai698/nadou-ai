# 助手会话存储模块化验收（2026-10-21）

本批把助手历史存储和纯回执编号从 HTTP 路由与画布执行器中分离，保持文件格式、锁顺序、幂等、执行归属和停止续行语义。整体模块化尚未完成。

## 职责、数据与依赖

| 模块 | 拥有的职责与数据 | 允许的依赖和入口 |
| --- | --- | --- |
| canvas_assistant_store | 用户/画布历史文件定位、原子读改写、线程与进程锁、会话和回合、执行编号归属、重启恢复、停止/继续领取、持久回执补偿 | 标准库、HTTPException、atomic_json、process_lock、纯计划规则和纯回执规则；路由注入根目录，写画布通过既有 apply_operations 回调 |
| canvas_assistant_receipt_rules | 用户和请求编号的 SHA-256 回执键 | 仅标准库 hashlib；operations 与 store 直接导入 |
| canvas_assistant | HTTP 请求、身份与画布校验、异步执行和流式响应编排 | 真实导入新 store/checked_id，调用原有工具和执行模块；不再定义存储类、编号校验或变更合并算法 |

存储不导入 main、路由、operations、工具或节点执行模块。操作执行器只迁走 receipt_key，其余逻辑没有改变。五个既有测试文件，包括函数内导入，全部转向实际归属模块；原定义和独占导入已删除，没有兼容包装或重复实现。HTTPException 依赖是既有错误合同，本批没有改变对外错误格式。
