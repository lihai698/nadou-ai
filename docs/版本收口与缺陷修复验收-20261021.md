## 隔离启动异常及处理

首次临时 UI 服务器使用内置 Python 启动，因其忽略脚本目录而误导入原工作区 main，读取了原目录配置。该测试进程已停止；当时已安装的网络限制禁止外部连接，没有调用真实供应商。

确认由本次创建的四个测试画布记录已按固定 ID 与标题双重核对后删除；两处无关页面缓存版本改动经与任务前快照对照后恢复。原目录启动流程含配置读取及资产迁移，本次没有取得这些私有数据的前后快照，不能声称已证明其全部字节未变。未输出配置内容。

修正后的临时服务器在导入前显式将自身目录放到 sys.path 首位，并断言 main.__file__、BASE_DIR 均位于沙箱；随后确认测试媒体 HTTP 200，重新运行了全部 11 项浏览器验收。上述通过结果仅来自修正后的隔离服务器。

核心检查启动器也显式固定临时源码导入路径，并排除 `workflows/custom/`，避免今后相同环境误用原入口或复制用户自定义工作流。发布筛选与 .gitignore 同时排除此目录，仅影响收集，不删除用户文件。
