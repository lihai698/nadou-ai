# 助手请求与公开数据模块化验收（2026-10-21）

本批将九个 HTTP 输入模型和三个公开数据投影函数从助手路由迁至明确归属，保持字段、校验、过滤、深复制和流事件格式。整体模块化尚未完成。

## 归属与实际调用

| 模块 | 职责和数据 | 依赖及入口 |
| --- | --- | --- |
| canvas_assistant_request_schema | SessionRequest、TurnRequest、ProposalAction、CancelRequest、ContinueRequest、PlanBudgetRequest、AuthorizationModel、AuthorizationRequest、NativeActionRequest | Pydantic、re、既有 Skill 模块的 BUILTINS 常量；不初始化目录、不读取 Skill 文件或历史、不加载路由和执行器 |
| canvas_assistant_session_views | public_skill_usage、public_native、final_event；仅接受传入字典并投影公开字段 | 仅 copy；历史/原生动作响应及流结束事件直接调用，无存储或执行副作用 |
| canvas_assistant | 路由、身份和画布版本校验、执行编排、流通信 | 只导入实际使用的八个输入模型和三个投影函数；AuthorizationModel 仅由 AuthorizationRequest 使用，不在路由保留转发导入 |

三处既有测试文件的所有输入模型导入，包括函数内导入，均迁向新归属。原定义及独占 Pydantic/BUILTINS 导入已删除。路由仍需要 re 处理既有错误文本，继续保留。Skill 编号沿用既有常量，没有另建一份允许名单。

本批只迁移公开数据投影，不调整字段过滤政策或数据访问权限；final_event 对既有列表和字典的引用方式原样保留。
