# 助手故事数据模型模块化验收（2026-10-21）

本批将故事生产、原文分析和逐镜操作的 11 个纯数据模型迁入 `backend/canvas_assistant_story_schema.py`，解除操作协议与这三类节点执行模块的导入依赖，保持字段、校验规则及执行行为不变。整体模块化尚未完成。

## 归属与真实入口

- story_schema 唯一拥有 StoryData、Asset、Sound、Beat、Dialogue、Shot、StoryWorkflow、StoryAnalysis、StoryAnalysisResult、ShotPrompts 和 ShotImages；仅依赖 Pydantic 及标准库，不读写画布、不加载执行器或 main。
- operation_schema、tools 直接导入新模块的数据模型；operations 直接使用新模型校验并交给原执行函数。story_analysis 复用 StoryWorkflow 生成分析指令及解析结果；shot_prompts 复用 StoryAnalysis 建立单镜处理节点。
- 原 story、story_analysis、shot_prompts 中的模型定义及专属导入已删除，没有旧模型转发或重复实现。剩余调用这些执行模块的导入均为实际执行函数。
- 执行模块间原有的调用关系保留：逐镜处理调用原文分析的节点构造，原文分析导入调用故事节点构造。本批解除的是协议对执行层的依赖，不宣称消除全部执行模块依赖。
- 知识索引只更新三个本批执行模块的已有源码摘要，不刷新其他窗口的来源。
