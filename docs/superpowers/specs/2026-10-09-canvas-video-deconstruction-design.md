# 普通与智能画布视频拆解：功能核对与接入设计

日期：2026-10-09。阶段：源码分析及界面方案已批准，产品源码已接入；自动检查与部分真实界面操作通过，剩余界面验收受浏览器确认框阻塞。详见 [实现与验收记录](../../视频拆解接入验收-20261009.md)。以下调查阶段记录保留为历史证据，不代表最终产品验收。

## 目标与边界

将参考项目当前真实实现的「按镜头拆」「拆成镜头表」完整接入普通和智能画布的视频编辑入口。普通画布和智能画布分别沿用各自颜色、浅深主题、Lucide、字号、边框、圆角、按钮、素材展示及任务状态；后端任务、镜头表数据和分析逻辑共用。保留视频预览、深度动作捕捉、原视频及用户画布。不是新增整个参考工作台，也不是把视频切成一批 MP4。

## 已确认的真实入口

- 本项目：`static/js/canvas.js` 的 `openImageNodeMenu`、`bindOutputWrap`、`openCanvasVideoEditor`；媒体型 image 节点和 output 视频均可进入。`CanvasDepthCapture.open` 是目前视频编辑面板；素材和生成结果均须支持，output 多视频按实际 URL 识别，不能只认节点第一项。
- 参考：`src/workbench/generationCanvas/nodes/NodeVideoFrameToolbar.tsx` 的拆解菜单；`NodeShotCutPanel.tsx` 与 `shotTable/factBridge.ts` 分别是两条真实入口。
- 本项目：`canvas-depth-capture.css` 已有面板主题、按钮及页签；`canvas.css` 定义 `--card/--soft/--line/--text/--muted/--strong/--strong-text`，不新建配色。
- 本项目已有 FFmpeg/FFprobe 工具定位及安全素材读取，可复用 `backend/canvas_clip.py` 的处理边界；有原生读图和图片生成链路。目前源码未发现语音转写接口，需要独立接入，不能用空对白代替完成。

## 接入方式选择

推荐：在现有视频编辑面板增加「拆解视频」下拉，保留两项名称；按镜头拆在该面板展示可选帧；镜头表落独立原生节点，点击“展开编辑”看完整表格。便于复用现有入口且不挤画布顶栏。

另外两种可行方案：右键增加独立拆解菜单（多一个入口，与用户指定位置不符）；替换整个视频编辑器（涉及无关改造）。本次不选。

## 提示词与模型数据流

独立中文分析规范：告知镜号及时间，明确输入三帧为同一镜不同时刻；汇总所有帧里的字幕、价格和角标，不只看中间帧。只请求 JSON：shotSize 为极特写/特写/近景/中景/全景/远景，mood 为 2–4 字，visual 为 30–60 字，onScreenText 多条用“ / ”分隔，无则空；imagePrompt 描述主体构图光线材质风格；motionPrompt 描述运镜与动作演进。逐个自定义列追加名称及分析说明，结果列 ID 和可见名称分离。

分析字段、原始量测字段、运行状态、选行与生成节点映射分别保存，事实表是分析结果唯一所有者；转成生成节点后的提示词由生成节点所有，不双向强制同步。源视频替换后旧表保留为旧素材分析，用户明确选择新素材才能建立新分析身份。

语音实现必须保留本地/云端能力。参考本地默认 large-v3-turbo-q5_0 多语言权重约 574MB，连同引擎及 VAD 总安装量应从经核对的清单计算，不能把参考宣称的速度当本机实测。采用开放上游组件、独立写适配层与许可说明；原 Nomi 具体文件不搬入本仓库。云端要求真实时间戳 segments；不支持者明示禁用，对白归镜不靠猜。

## 界面与预览

现有视频编辑上方“预览 / 深度动作捕捉”保留，在同一区域加拆解下拉。按镜头拆：视频预览、灵敏度、帧网格、全选和加入画布。镜头表：先本地分析，再展示原生模型选择及整批调用确认，完成后在画布显示表节点，可展开编辑。桌面完整表横滚，手机使用镜头卡片逐条编辑，均支持六内置列、自定义列、提示词、选行与重试。

预览标示“示例界面”，素材是自制示意图，不读取用户画布；所有检测/分析/生成示例均不调用真实模型、不落用户数据。浅/深主题使用真实 canvas.css、canvas-depth-capture.css 和 Lucide。预览不是功能验收证据。

## 实施顺序与完成条件

1. 本地检测、PTS联系表、选择抽图、原生网格/分组；用自制多镜/单镜/密集切点媒体验证。
2. 镜头表数据与原生节点、编辑、自定义列、缩放、选行、保存重开/复制/导入导出。
3. 视觉多帧与本地/云端对白转写、逐批确认、取消/单镜重试；模拟模型验证全链，无付费调用。
4. 生成所选接已有批生成节点链，稳定身份去重；验证编辑保留、同源复用、切画布/撤销/重启和输出多视频边界。
5. 浅深主题、桌面/390px窄屏真实界面操作与截图；用户验收确认后仅提交本功能源码、测试和说明，再正常推个人仓库，不发布安装包。
