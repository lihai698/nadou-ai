# 普通媒体输入事件与上传目标归属

复用已有媒体解析、上传与节点模块，保持原拖放优先级、限制、错误及保存行为。

1. 真实上传入口先复现切换画布及同ID重开后的晚回写入；保留原不完整上传及分组重连断言。
2. 六组board/window拖放及媒体paste注册迁入一个生命周期控制器；控制器提供捕获当前画布ID、既有打开代次和挂载代次的有效性检查，供上传模块通过host调用。
3. 迁移媒体选择器主体；异步解析、上传、局部替换及本地路径回包在写入前检查目标，离页时解除监听/清除拖放覆盖层。避免用会被自动保存替换的canvas对象作为切换标志。
4. 专项、完整前端、原主体/依赖及独立审查；隔离页面上传与保存重开；文档明确工作流导入和智能画布晚回不在本批。
