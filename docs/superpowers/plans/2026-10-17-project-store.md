## 接口与归属

- `ProjectStore(path, *, lock, now_ms, new_id, default_id)`：不持有进程外全局路径；lock 必须为可重入锁。
- `load()`：缺文件返回空列表；旧数组/当前对象均可读；损坏或未来版本抛 `ProjectReadError`，只包含原有公开错误说明及 status_code。
- `save(projects)`：锁内先检查已有文件可读，复用现有格式标记和原子替换；失败保留原文件，输入验证异常保留原行为。
- `ensure_default()`：锁内幂等创建默认项目，不改任何画布。
- `create(name="新项目")`：锁内初始化、清理名称、分配排序和 ID、保存并返回原完整记录。
- main 通过局部上下文包装把 ProjectReadError 转为 HTTPException，兼容四个旧函数名。兼容包装仍供路由和测试使用，不复制业务逻辑。

## 审查重点

1. 缺文件、旧数组、未知字段、损坏 JSON、未来格式的行为保持。
2. 保存失败与新建失败不覆盖原文件、不返回假成功。
3. 多线程共享锁跨不同 Store 实例创建时不丢项目，默认项目只有一个。
4. HTTP 状态码、公开字段、名称和排序不变；未来格式和坏文件拒绝覆盖。
5. 项目删除失败可重试和画布内容保留仍由原回归验证。
