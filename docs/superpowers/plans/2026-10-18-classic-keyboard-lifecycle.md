# 普通画布快捷键职责及延迟粘贴归属

保持现有快捷键、输入框保护、预览导航、选择与拖动结束行为。将 main 四组键盘/blur 注册迁入单一控制器，原业务状态由显式 host 拥有。

1. 真实原事件固定正常复制粘贴及媒体剪贴板优先；先复现延迟粘贴在画布替换、离页和失焦后仍执行。
2. 迁移四组主体、删除原注册；控制器管理监听及待执行粘贴计时器，按画布 id、原有打开代次和挂载代次检查目标。自动保存会替换画布对象，不能用对象身份代表重新打开。
3. 保持已有快捷键回归断言；专项、完整前端、AST/依赖审计、独立审查及隔离页面复制粘贴/保存。
4. 更新知识来源摘要和验收记录，不提交、推送或调用生成。异步媒体上传归属不混入本批。
