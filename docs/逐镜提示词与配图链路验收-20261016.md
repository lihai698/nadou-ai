# 逐镜提示词与配图链路验收

日期：2026-10-16。范围：继续现有创作助手阶段；不扩展 Skill 安装、规划调度，不改变拆分与循环。

## 实际验证

- 普通与智能画布：创建两镜处理流程；每镜素材连接真实原生 LLM 节点，模型选择取当前配置。
- 修改第 1 镜后，未重新运行 LLM 的旧结果不能创建配图；更新处理结果后，新建第 1 镜配图分支。
- 第 2 镜的素材、处理节点、配图节点和旧图片逐项保持原样；第 1 镜旧图也保留。旧配图分支不再允许用已失效素材重复运行。
- 智能画布实际界面：运行单镜 LLM，模拟接口核对系统规则和单镜原文；选择图片节点运行，模拟图片接口收到的 prompt 与 LLM 顶部结果完全相同。
- 模拟返回现有应用 logo 作为测试图片，只用于检查图片加载与保存，不代表故事出图效果；保存重开后图片仍能加载。
- 请求与画布证据：output/shot-chain-evidence.json；截图：output/shot-chain-verified.jpg。隔离数据和截图不提交。
