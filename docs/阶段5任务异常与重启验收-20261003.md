# 阶段 5：任务异常与重启验收（2026-10-03）

在线图片任务已有普通、智能画布的本机模拟故障与真实隔离服务进程重启页面证据，见[核心流程验收清单](核心流程验收清单.md)的 F07。这里补查独立的 ComfyUI 任务接口。

使用真实 `/api/canvas-comfy-tasks` 路由，生成器由本机可控函数替代，不连接 ComfyUI 或收费服务。提交后确认为 `running`；模拟读取超时、连接中断及生成器报错后，均变成 `failed`，保留错误原因，结果为空。重复 GET 不再次生成。进程退出时任务仍在运行；新进程查原编号得到 404，并说明可能已重启或任务已过期。

两种画布的 ComfyUI 查询函数原先遇到一次 503 或网络中断就结束。本轮改为只对原编号限次 GET 重试，等待 1、2、4 秒；连续失败后停止。404 和明确生成失败不重试，智能画布 404 给出中英文重启提示。自动测试覆盖上述分支，6 项通过；后端 2 项和进程重启专项 3 项通过。原始结果见[隔离证据](evidence/20261003/stage5-comfy-fault-restart.json)。

本轮没有更换旧任务接口；两种画布原来的 ComfyUI 调用仍走同一入口。已受理的 ComfyUI 编号尚未持久保存在画布，关闭页面后无法从旧编号继续查询；后台重启也无法恢复内存任务。持续故障只会结束当前查询，不代表远程任务已取消。ComfyUI 真实页面按钮、真实 ComfyUI 与供应商远端状态未验证，故这部分只能记为部分通过。
