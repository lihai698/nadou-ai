# 助手画布公共规则模块化验收（2026-10-21）

本批将画布快照摘要、用户生成设置校验和连线规则归入 `backend/canvas_assistant_canvas_rules.py`，移除原生动作及循环模块对操作编排器的依赖。没有改变助手操作协议或产品行为，整体模块化仍未完成。

## 职责及依赖

- 公共画布规则拥有 `content_hash`、`generation_settings`、`allowed_connection`、`would_cycle` 的唯一实现，仅使用标准库和 FastAPI 异常；接收画布、连接、用户设置及供应商目录，不读取文件、配置、凭据或网络，不依赖操作编排、原生动作、循环或 main。
- operations 仍拥有计划解析、回执编号、操作编排和候选文档构造，使用公共规则。native、loop 和助手会话入口的实际调用均迁到公共规则；测试直接从职责所属模块导入。
- 原生动作和循环现在可在禁止加载 operations/main 的独立进程中导入；此前会触发反向依赖的回归已先复现失败，迁移后通过。原有公共节点规则的独立性保护仍保留。
- 四个迁移函数的 AST 与旧实现完全相同；四个既有生产模块除导入及迁走定义外的可执行 AST 完全相同。旧定义已删除，未添加重复实现或转发包装。
- 节点原生字段归公共节点规则；持锁写入、任务执行、凭据、模型服务及前端事件状态仍归原模块。本批未修改 main、双画布 JS、CSS 或智能提示词前端。
- 知识索引仅更新本批 native 来源的 5 处摘要。未使用混合工作区重新认证其他来源。
