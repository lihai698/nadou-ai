# 阶段 8：画布素材引用规则试拆

日期：2026-10-04  
范围：把画布节点中素材 URL/路径提取、可下载边界、媒体类型和展示文件名规则移到 `backend/canvas_asset_rules.py`。本次只处理无状态值转换，不扫描或修改画布、素材目录和其他用户数据。

## 职责、数据和依赖

| 模块 | 负责 | 不负责 | 数据所有权 |
| --- | --- | --- | --- |
| `backend/canvas_asset_rules.py` | 从节点值提取 `url/path/src/...`、保留 `/assets/`/`/output/`/HTTP(S) 引用、判断显式或扩展名媒体类型、清理展示名、递归扫描节点值 | 读取画布文件、素材文件、配置、网络下载、删除、写回和 FastAPI 响应 | 不拥有持久数据，只处理调用方传入的值 |
| `main.py` | 加载画布并组织 `extract_canvas_assets`/`canvas_assets_index`，把规则结果组装为公开索引；继续持有文件锁和读写入口 | 不再重复实现素材引用解析和文件名清理规则 | 画布 JSON、素材索引和媒体文件仍由现有入口及对应模块管理 |

允许依赖方向为 `main.py -> backend.canvas_asset_rules -> backend.asset_media_rules`。新模块只依赖 Python 标准库和已有无状态媒体类型规则，不导入 `main.py`、FastAPI、目录配置、网络客户端或用户数据。`main.py` 通过同名导入保留原内部调用方式，旧函数体已删除。

## 兼容边界

- URL 字段优先级仍为 `url`、`path`、`src`、`uri`、`output`、`output_url`、`outputUrl`、`video`、`video_url`、`videoUrl`。
- 可索引引用仍只接受 `/output/`、`/assets/`、`http://` 和 `https://` 开头的值；`blob:`、`data:` 和相对文件名不会进入画布素材索引。
- 显式 `kind/mediaKind/type` 中的 video/audio/text/workflow 仍优先于 URL 扩展名；未知值继续交给素材库媒体类型规则。
- 递归扫描仍跳过 `run`、`runs`、`settings`、`params`、`metadata`、`meta`、`prompt`、`text`、`caption`、`logs`，并保留原字段路径和重复 URL 行为；`extract_canvas_assets` 仍负责按 URL 去重。
- `sanitize_asset_name`、`sanitize_export_filename` 和 `filename_from_media_url` 继续保持原截断、basename、非法字符替换和 URL 解码规则；没有修改画布 JSON 格式或素材文件名。

## 验证

`tests/test_canvas_asset_rules.py` 5 项通过，覆盖主入口兼容导入、URL 边界、显式类型优先级、中文文件名与非法字符、递归扫描路径和跳过运行字段。`py_compile` 覆盖新模块、`main.py` 和专项测试；`git diff --check` 通过。`rg` 确认生产代码只保留新模块中的 8 个规则函数，没有 `main.py` 反向导入或第二套函数体。

专项测试只使用自制字典、URL 和字符串，没有读取或写入真实 `data/`、`assets/`、画布、素材索引、API 配置，也没有调用供应商。画布索引整体接口仍需随阶段 8 联合检查一并验证。

## 限制与恢复

本次不改变素材删除、引用保护、目录迁移和跨进程协调；这些操作仍属于现有存储/素材入口，后续需通过公开只读引用接口继续收敛。若需恢复，删除该模块和专项测试，并将已删规则函数恢复到 `main.py` 对应调用点即可；画布和素材数据格式无需迁移。
