# 画布布局调整与本地验收

## 已确认范围

用户确认采用“专注画布”方案，并要求任何功能不改变。本轮调整主界面左侧导航和普通画布顶部入口；沿用既有颜色、字体、图标和按钮。智能画布的编辑器布局保持原有实现。

## 入口对照

| 原入口 | 新位置 | 原功能 |
| --- | --- | --- |
| 无限画布、素材库 | 左侧最上方 | 使用原独立页面和切换函数 |
| 在线生图、GPT 对话 | 左侧中部 | 使用原独立页面，保留原配置与记录 |
| 文生图、细节增强、图片编辑、角度控制 | 左侧“本地功能”浮层 | 原四个页面全部保留 |
| API、工作流设置、主题、语言、缩放、GitHub、更新、版本检查 | 左下方“更多设置”浮层 | 原控件、事件和条件显示保留 |
| 顶部节点栏 | 空白处右键；右上方“更多 → 节点菜单”备用入口 | 原13种节点的创建菜单及函数保留 |
| 分组 | Ctrl 框选多个节点后自动成组；多选操作区；“更多 → 分组”；Ctrl+G | 包含全部选中节点，保留单节点分组和创建空分组；R 框选仍只多选 |

浮层支持点击外部和 Escape 收起；较矮窗口的导航仍可滚动。节点菜单限高后可滚动至最后一项，菜单内滚轮不触发画布缩放。分组入口随画布平移定位。外层画布使用裁剪，防止节点输入框聚焦令固定工具栏发生滚动。

## 关键源码

- `static/index.html`：左侧入口排序、浮层锚定与关闭、原页面切换。
- `static/canvas.html`：普通画布顶部入口和更多菜单。
- `static/css/studio-layout.css`：导航、浮层和画布工具位置，使用原主题变量。
- `static/css/canvas.css`：清理已替代的旧节点栏样式。
- `static/js/canvas.js`：更多菜单、节点菜单定位和选中后的分组入口。
- `static/js/i18n/canvas.js`、`static/js/i18n.js`：新入口中英文标签及缓存版本。

移除了旧节点栏 HTML、样式、折叠状态和监听器，没有留下另一套节点栏。未替换节点创建、生成、分组、清空或保存的处理函数；与实施前备份逐一比较的20个相关函数正文完全一致。本次没有修改后端或用户画布数据。

## 单节点显示分组按钮修正（2026-10-09）

用户反馈拖动单个节点也出现“分组”，容易误以为自动创建了分组。浏览器实际复现确认：单节点拖动后节点数量不变、分组节点数量仍为0，但浮动快捷按钮确实出现。根因是 `renderSelectionHub()` 的显示条件允许只选中一个可分组节点。

仅把快捷按钮显示门槛改为至少两个可分组节点（图片或提示词，包括以图片节点承载的视频素材），单节点拖动不再显示；混合选中一张图片和不可分组的生成器时也不显示。`groupSelectedImages()` 保持原实现，“更多 → 分组”和 Ctrl+G 继续支持单节点分组及空分组。更新普通画布脚本缓存版本，以便刷新加载修正。

修正前的隔离浏览器检查实际失败于“单节点拖动后快捷按钮应隐藏”；修正后单张图片、其他图片、提示词、生成器及视频素材拖动检查通过，均未增加分组节点。多节点创建分组与撤销、单节点 Ctrl+G、菜单创建空分组检查通过，无页面脚本错误。分组复制和原生快捷键相关5项检查、脚本语法及差异空白检查通过。所有浏览器 API 写入均被模拟拦截，未触碰真实画布；待用户验收，未提交上传。

## 多类型节点整体分组修正（2026-10-09）

用户明确反馈 Ctrl 框选图片、API 生成、输出三个节点时希望自动成组，Ctrl+G 也应把三个节点全部包住。核对旧函数确认原先只收集图片/提示词，框选结束也只多选。本次按这项新明确要求替换相关条件：

- Ctrl/Command 框选结束时，至少两个节点自动创建组；单节点不自动成组。R 框选继续保留纯多选，之后可用按钮、Ctrl+G 或更多菜单分组。
- 分组成员包含全部选中的节点类型，边界根据全部成员尺寸计算；顶部留白增加，避免成员遮挡数量说明。混合节点组显示总节点数，拖动组时所有成员一起移动。
- 已选中单个组时再次按 Ctrl+G 不再创建重复嵌套组。多选浮动分组按钮支持所有节点类型，单选仍不显示。
- 含生成器、输出等节点的组保存 `groupMode:workflow`，只组织布局，保持原输入/输出连线与参数。纯图片/提示词素材组继续保留原有接管输入连线的功能；拖入拖出工作流组更新全部普通节点类型的成员关系，不改连线。
- 新增 `tests/canvas_group_selection.test.cjs`，修正前实际出现4项行为失败，修正后5项通过。联同分组复制、原生快捷键、保存恢复共14项检查通过。
- 隔离浏览器使用真实前端执行 Ctrl 框选自动成组、R 框选＋Ctrl+G、完整包围三个成员、重复快捷键、撤销、整体拖动和保存重开，原连线和参数保持；检查手机显示，无页面脚本错误。所有 API 写入模拟拦截，不写入真实画布，未调用生成服务。
- 本次修改普通画布的 `static/js/canvas.js`、脚本缓存入口 `static/canvas.html`、上述测试和本文；仍待用户验收，未提交或上传。
