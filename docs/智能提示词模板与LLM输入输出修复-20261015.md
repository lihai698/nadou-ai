## 使用流程

1. 智能提示词开启 LLM，手动选择平台和文本模型。
2. 引用模板：写入模型下方的处理规则框，作为系统提示词；上游原文显示在下方输入区。
3. 点击运行：规则和上游文本分别发送给模型。
4. 成功后结果写入顶部文本框，连接下游读取这一结果。

普通文本节点关闭 LLM 时，模板仍写入正文。附加系统提示词开关保留，用于叠加额外规则。

## 替换的旧逻辑

- LLM 模式引用模板不再覆盖顶部输出；保存模板取中间规则框。
- 模型输入不再用顶部旧结果补齐，也不把规则混进原文。
- 规则或模型变化后保留旧结果，但阻止旧结果向直连、分组、relay 下游及逐镜配图工具传播；重新运行成功才恢复。
- 空结果、失败或运行中改变规则、模型、开关、上游文本/图片/视频时，不覆盖原结果和当前模型选择。
- 已有用户节点正文不自动搬移或清理；旧模板如在顶部，请重新引用一次。

## 关键文件

- static/js/smart-canvas.js：模板应用/保存、模型请求、结果更新与下游读取。
- static/js/i18n/smart-canvas.js：规则框提示文字。
- backend/canvas_assistant_native.py：模型输入预检排除旧输出。
- backend/canvas_assistant_shot_prompts.py：拒绝过期处理结果。
- tests/smart_prompt_template_flow.test.cjs、tests/test_canvas_assistant_native.py、tests/test_canvas_assistant_shot_prompts.py：相关回归。
