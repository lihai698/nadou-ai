# 通用视频激活与预览监听归属验收（2026-10-19）

状态：专项、独立审查与实际页面通过，完整核心待结束。整体模块化未完成。本批只处理通用预览监听和视频激活，不重做播放恢复、高清预览、尺寸、输入面板或图片编辑器。

## 职责与归属

- 新增`static/js/smart-preview-events.js`；主入口的`smartActivateVideoPreview`、`bindSmartPreviewImageFallbacks`保持原签名薄委托，HTML加载及媒体输入控制器之后的挂载已接入。
- 控制器统一注册document捕获阶段的`error`和`ended`监听，以WeakMap标记已绑定的DOM。已删除原逐图片错误监听、逐视频结束监听和smart入口的`previewFallbackBound`标记；不会保留一份强引用DOM清单。
- 节点预览验证画布ID/打开代次、容器与引用节点、图片槽位、模型URL和实际显示URL。正常保存替换对象后，视频结束写入当前素材，不写入旧对象；分组引用也写入实际成员。沿用`imageForDisplay`支持远端结果对应本地显示地址。
- 非节点预览只核对DOM连接、绑定区域、父元素和来源，不要求存在打开的画布；保留素材面板、日志、输入缩略图、mentions及编辑器比较缩略图的通用用途。节点与非节点归属不能相互套用。
- 图片失败仍回退到原图；视频失败仍采用原fallback模板及attrs。视频激活采用原播放器模板；已有fallback播放器继续保留controls/unmute/play行为。本批没有更换UI、模板、数据格式或供应商接口。
- document捕获阶段先执行预览回退，再到原元素的proxy回退，保持真实render的原有顺序；视频替换后，原proxy控制器的连接检查会阻止旧图片操作。
- `pagehide`移除document监听并释放WeakMap记录；`pageshow`重新绑定当前DOM且只注册一次；`dispose()`同时解除window监听并禁止重挂载。无新依赖，不读取私配。
