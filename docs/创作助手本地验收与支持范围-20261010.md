# 创作助手本地验收与支持范围

日期：2026-10-10。用户最新决定：暂不追加真实 GPT CLI 文本/视觉请求，只完成本地开发和模拟验收。本文件说明当前实际支持的合同；不是剩余407项全部原生功能通过证明。

## 当前入口

普通与智能画布仍使用原创作助手。模型分别手选，执行操作需要确认。使用根目录 `run.bat` 启动，再打开相应画布；没有更换界面、复制另一套应用或新增供应商队列。

已接入节点知识/白名单读取、受控原生动作、持久计划与依赖、停止/断线恢复，以及图片硬条件/有限视频核验。原任务编号和保存回执决定完成状态；未知受理不能自动重提。生成质量、全片语义和音质不因模拟通过而合格。

## 原生操作支持范围

| 画布/节点 | 助手当前合同 | 仍需原手动入口或单独验收 |
| --- | --- | --- |
| 普通 image / output | 读取、预览、标题、受限连接、工作流导出；沿用原素材与结果 | 裁剪、遮罩、画笔等图像工具不属于通用update |
| 普通 prompt | 创建、正文/标题、连接、读取与工作流导出 | 模板等显示按钮按原界面操作 |
| 普通 loop | 创建、允许字段、循环提示词与连接 | 不作为独立生成器运行，实际生成由下游合同决定 |
| 普通 group / promptGroup | 创建、受限成员/连接、读取与导出 | 删除原素材、嵌套吸收不自动开放 |
| 普通 llm | 原节点手选模型的一次文本运行、原正文保存、同步回执与计划续行 | 真实文本/视觉理解效果未增加验收 |
| 普通 generator | 原API图片运行，1–8任务，保留原参数、原任务恢复与结果归属 | 音频分支不能用图片合同执行 |
| 普通 midjourney | 首次imagine/blend/edit，count=1，保留原模型与远端任务编号 | U/V、remix、zoom/pan等续作不自动追加 |
| 普通 msgen | ZImage、Qwen、Klein、自定义模型首次单任务；当前自定义模型LoRA合同 | 其它复杂上游/批量组合不由首轮样例覆盖 |
| 普通 video | 原手选视频模型的单任务、输入/输出绑定、原任务查询与保存 | 未调用真实视频供应商，整片质量不作保证 |
| 普通 rh | 手选model/workflow/app运行，动态schema参数编辑与原任务恢复 | 依赖真实配置；不代选模型/工作流或猜schema |
| 普通 comfy | 原工作流单任务；增强/编辑超分最多两任务，动态参数合同 | count不是重复工作流任务次数，不能据此扩量 |
| 普通 clip | remove/move/trim，全片/逐段媒体导出到画布或下载 | 分割等其它按钮仍按原入口使用 |
| 两画布镜头表 | 行/列/选行编辑、原生生成链创建、状态/归属读取 | 分析/语音重试不等于自动有新调用许可；助手copy未实现 |
| 智能 image | 空图片节点API图片运行，明确1–8任务，原结果恢复 | 已有图片重跑、扩图、其它引擎及音视频分支未开放 |
| 智能 prompt | 正文/允许参数、手选文本模型LLM运行 | 原音视频分析和真实模型质量另行核验 |
| 智能 loop | API图片顺序/并行、直接叶或单根DAG、持久轮槽与剩余预算 | 多根、嵌套loop/group及其它引擎不由本合同覆盖 |
| 智能 group | 受限成员、API图片聚合，创建独立结果分支并保留原图 | 吸收删除原图片、嵌套生成链与其它引擎未开放 |

实际开放目录由 `backend/canvas_assistant_native.py:native_catalog` 返回；预检会按配置/状态继续收紧。`plannedActions=[]` 只表示目录所列动作没有待实现项，绝不代表所有原生按钮都可被助手执行。
