# 图片节点视角调整：接入与验收对照

2026-10-07。范围仅为用户指定的多角度、打光；普通和智能画布共用参数与提示词规则，分别接入各自原生 API 图片节点。

## 已落地的入口和流程

普通画布：图片右键 → 编辑 → 视角调整 ▾ → 多角度／打光。

智能画布：选中图片 → 图片上方工具栏 → 视角调整 ▾ → 多角度／打光。

调整参数、选择本项目后台模型 → 创建 API 节点 → 原图连线、提示词和所选模型自动带入 → 在原生节点中继续改提示词／模型 → 手动运行。创建按钮仅操作画布数据，不调用生成服务，不覆盖原图片。

## 数据流与边界

- 普通画布使用原生 `generator`，节点内提示词接入现有 `generatorSources()`，执行仍走原 `runGenerator`。
- 智能画布使用原生 `smart-image` 的 API 图片模式，预填节点提示词草稿，连接原图。多图节点仅默认启用用户选择的图片，其余可在原生参考图区重新开启。
- 参数和模型草稿保存在源图片中，创建的节点包含参数记录；保存重开仍保留提示词、连线和模型。
- 智能工作流导入、复制粘贴和拖动复制会重映射来源标识及禁用参考图标识，避免指向旧节点。
- 创建按钮在加载中／保存中禁用，成功后禁止重复创建；原图失效或配置失效会显示错误。保存失败说明节点已创建、应重试保存。
- 普通画布按实际渲染后的 API 卡片尺寸避让已有节点；智能画布复用原有输出节点定位，连续创建向下排列。
- 不新增执行服务或模型依赖。两种画布的模板入口、裁剪、扩图等现有功能保持原流程。
