# 创作助手能力说明校准（2026-10-17）

## 本次目标

把创作助手的能力说明改成与真实源码一致，避免把“整条能力尚未全部验收”误解成“功能尚未接入”。本次只校准说明、知识证据和测试，不改变节点动作、自动执行白名单、模型选择、调用预算或确认规则。

## 已校准内容

- 原生节点目录按类型说明实际能力：读取、创建、连接、编辑、查询、恢复、导出或运行。
- 可运行节点明确沿用用户已经选择并保存的模型；只有本轮授权和调用上限允许时才自动推进。
- 不可独立运行的节点明确说明生成工作必须交给对应运行节点。
- 智能图片节点的助手运行当前只开放空节点 API 图片生成；视频和其他引擎继续走原入口。
- LLM 与智能提示词节点明确区分系统规则、上游原文和模型结果。
- 循环节点保持现有逐轮输入逻辑，不根据普通文本自动推断分段。
- 视频节点明确当前作品检查只覆盖有限关键帧，不代表全片和音频语义已经验收。
- ComfyUI 明确没有远端取消能力；恢复和查询继续使用原任务编号，受理状态未知时不重复提交。
- 音频继续保持助手只读，不开放助手发起音频供应商任务。

## 验收状态的含义

- `documented/readable`：说明存在，并且知识条目可以读取。
- `actionable/verified = pending`：该条能力尚未完成全部动作、界面和真实供应商效果验收，不表示所有功能都没有接入。
- `coverageEvidence`：记录已有自动测试和仍未验证的边界，只作为事实资料；真实可用动作仍以原生节点合同和当前配置为准。
- `classic.audio` 单独保持只读状态和部分本地验收结论。
