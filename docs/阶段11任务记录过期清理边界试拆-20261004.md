# 阶段 11：任务记录过期清理边界试拆

日期：2026-10-04  
范围：图片和 ComfyUI 本地任务记录的显式过期清理规则。只使用临时目录和自制 JSON，不读取真实 `data/`，不连接供应商。

## 本轮实现

新增 `backend/task_record_cleanup.py`，把清理分为两个必须由调用方显式执行的步骤：

1. `plan_expired_task_cleanup(root, ttl_seconds, now)` 扫描指定目录并生成计划，不删除文件。
2. `apply_task_cleanup_plan(plan)` 重新检查计划中的文件，再删除候选记录。

计划只接受 `succeeded` 和 `failed` 两种已经确认结束的状态，并要求记录包含有限的 `updated_at` 或 `created_at`。更新时间优先；缺少两个时间字段的旧记录会保守保留，不猜测文件修改时间。`queued`、`running`、`unknown` 和 `jimeng_pending` 永远进入保留列表。

任务编号继续使用 `backend/task_records.py` 的 `canvas_img_`/`canvas_comfy_` 规则。扫描只看指定目录的直接子项和匹配的 `.json` 文件；目录符号链接、文件符号链接、非普通文件、非法候选编号和越界路径都会拒绝。匹配编号的 JSON 损坏或时间无效时，计划直接失败并保留故障现场，不把异常正文返回给调用方。

应用计划前会再次检查路径、普通文件属性、文件摘要、任务状态和时间戳。计划建立后记录被改写、变成非终态、变得不再过期或消失时，应用会停止，避免按旧快照删除。计划和应用区间持有任务记录目录的跨进程文件锁。开始删除前，还会在同目录的 `.task_cleanup_recovery_*` 私有目录中为全部候选建立独立副本并核对摘要；只有完整备份完成并写入 `.ready` 标记后，才逐个删除原文件。删除中途失败时，程序会自动恢复缺失的候选，成功完成或恢复后清理备份。

模块导入没有副作用，也没有接入启动流程或任何自动删除入口。任务记录读写、计划扫描和显式应用共用指定目录的跨进程文件锁，避免维护快照与本地写入交错。新增 `GET /api/maintenance/task-records/cleanup-plan` 作为受控只读维护入口：它在当前进程任务锁内生成计划，只公开 TTL、候选编号/状态/年龄和保留数量，不调用 `apply_task_cleanup_plan`，不会删除任何记录。默认 TTL 只是显式计划函数使用的 30 天维护工具默认值，不代表服务启动会自动清理；视频任务目录仍不纳入本入口。当前阶段不勾选“自动过期清理”完成。

如果自动回滚本身失败，`TaskCleanupRecoveryRequired.recovery_dir` 指向保留下来的副本目录。维护者应先停止该目录的写入，在备份中核对 `.ready` 与候选 JSON，只把缺失的原文件恢复到任务目录，不能覆盖已经存在且可能被改写的记录。进程突然退出或断电后也可能留下这个目录；当前没有启动自动恢复或回收入口，需在维护窗口人工核对。若全部原文件已成功删除、仅备份目录清理失败，异常会明确说明“候选记录已删除”，仍须人工清理残留副本。

## 隔离验证

`tests/test_task_record_cleanup.py` 共 11 项通过，另有 `tests/test_task_record_cleanup_route.py` 维护入口 2 项通过；任务记录基础规则 10 项和跨进程锁等待 1 项通过，覆盖：

- 旧 `succeeded`/`failed` 进入候选，近期记录和四种未结束状态保留；
- 显式应用计划只删除候选记录；
- 匹配任务编号的损坏 JSON 使计划失败且不删除其他记录；
- 计划建立后记录变化时，在删除前整体停止；
- 第二项删除失败后自动恢复全部候选且无残留副本；备份建立失败时不删除；回滚失败时保留可人工恢复的副本；
- 非法 TTL 和越界候选编号拒绝；
- 手工构造的重复候选编号在删除前拒绝；
- 非任务文件和嵌套目录不扩大扫描范围。
- 对外计划摘要不包含本地路径、文件摘要或 inode 信息。
- HTTP 计划入口只读，未完成任务保留；TTL 无效或记录损坏返回固定错误且不回显记录正文。

## 尚未完成的边界

- `main.py` 仅接入只读计划入口；没有应用计划的 HTTP 入口，服务启动不会自动扫描或删除任务记录。正式删除仍需维护脚本显式持有计划并调用 `apply_task_cleanup_plan`。
- 任务记录目录已有跨进程锁与删除异常自动回滚，但没有跨文件原子事务、供应商远端状态对账或视频任务记录。
- 应用计划与绕过目录锁的外部文件修改之间仍存在检查后竞态；进程突然退出、断电或回滚自身失败仍需要维护窗口人工恢复与故障演练，正式开放删除入口前还需确认这些流程。
