日期：2026-10-21。基线 `c20b40597c5c5e1d7e134794e1a0bcbb2f413c9f`；固定候选树 `25ac46c384f5751def919708a6a229b56e4a3730`。本批为内部职责迁移，保持原接口、文件格式和行为。

## 职责与状态归属

| 归属 | 从原 router 迁移的完整职责 | 数据与调用边界 |
| --- | --- | --- |
| `canvas_assistant_session_service.py` | `identity`、`status`、`get_canvas`、`reference_assets`、`sessions`、`create`、`history`、`cancel` | 身份检查、公开目录与会话读写；使用 host 注入的原 store、running 与画布读入口 |
| `canvas_assistant_agent_runtime.py` | `drive_agent`，包括所有嵌套工具、检查点和执行回调 | 使用原 agent、领域策略、任务/画布能力；会话持久化仍通过原 store |
| `canvas_assistant_native_actions.py` | `current_workflow_fields`、`native_action`，包括嵌套事务 | 原生动作准备、授权、原任务确认/查询/完成；使用注入能力，不另建状态或锁 |
| `canvas_assistant_turn_service.py` | `stream_response`、`completed_results`、`continue_turn`、`change_proposal`、`proposal_action`、`chat`，包括嵌套生产任务与清理回调 | 对话生命周期、原提案事务和 NDJSON 流；共享原 running/store，保留断线与显式停止区别 |
| `canvas_assistant.py` | 原路由签名、装饰器、原 factory 装配和单行转发 | 每次 factory 创建且只创建原有 store、running、skills、knowledge、result inspection；继续注册原入口 |

之前已迁移的预算/授权仍由原 budget service 处理。四个新服务没有顶层导入或模块可变状态；原 `get_canvas` 函数内部的标准库导入保留。服务不反向导入 router/main，不创建另一份会话状态或锁。所需依赖通过具名参数显式注入，正文使用原接口。

- 新增 14 项服务边界测试：旧树正确失败；候选在阻断应用入口、router、store、agent、operations 导入时通过。覆盖身份顺序、会话/历史、取消、工作流字段、driver 短路、结果读取、原事务、流输出及断线任务清理。
- 对 136 个 backend 模块检查顶层与嵌套显式导入，没有显式 main 反向导入和循环；四个 owner 不含 backend 导入边。该检查不证明动态插件的任意运行时导入。
- 相关测试：基线 677、候选 691，各跳过 2 项；固定候选完整核心检查：Python 1494、JavaScript 1193 项通过。未删除、屏蔽原测试。

## 双画布与生命周期

基线和固定候选都通过普通/智能画布真实 Chrome：素材来源与编号、拖入和下载、图片/视频任务刷新、保存重开、强制重启恢复。两画布的 ZIP 导出实际触发浏览器 download event，条目名称及内容字节相等。原生 FFmpeg 自制媒体分别覆盖保存到画布和下载，确认原任务不重复提交、字节和重启后任务引用保持。六张候选截图的拼图已检查。

会话生命周期、结果检查取消隔离、32 个独立进程的 store 锁与写入无丢失通过。没有读取真实用户画布/素材或私配，没有调用真实供应商或收费生成。供应商模型效果、动态插件、长期性能不在本批验证范围。
