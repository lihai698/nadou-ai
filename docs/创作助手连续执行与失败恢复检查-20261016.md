# 创作助手连续执行与失败恢复检查

日期：2026-10-16。状态：本地修复与验证完成，用户已确认，纳入本次源码提交同步。

## 范围

检查已有创作助手的连续执行、任务面板和失败恢复。普通与智能画布共用 static/js/canvas-assistant.js。本轮不改节点类型、拆分、循环、Skill 安装与规划，也不改授权额度或自动重试边界。

## 已确认的问题及修复

1. 自动操作出错会写入 autoErrors，阻止后续自动执行；原任务成功同步后旧标记仍可能残留。现在仅在同步成功、原动作 completed、且画布和会话仍匹配时清除旧错误并恢复推进；同步失败保留错误和原任务。
2. 手动继续入口没有统一清除旧暂停标记。现在有效进入继续请求时清理旧错误，新的失败仍由 catch 记录。忙碌、无会话时不清除状态。
3. failed 的 Agent 回合缺少统一的继续入口。现在任务面板提供“继续创作”，按原回合继续，不要求重新发送需求。
4. 继续运行时收起旧任务详情，进度使用现有任务入口与轻量“正在创作”指示；错误和步骤记录仍可打开查看。

替换的是上述旧处理分支，没有新建另一套执行器。失败和受理未知的原任务仍禁止自动重提；本修复不意味着所有供应商失败都能自动恢复。
