## 结果与使用

普通、智能画布均已接入本机持久草稿。修改在编辑过程中写入浏览器 IndexedDB；只有事务完成后才显示“已备份本机”，此状态不等于画布已保存到服务。保存失败后关闭标签，再打开同一画布，恢复未保存正文及节点、分组、连线。冲突沿用原三方合并规则，保留两份正文和副本连线，检查后点击“重试保存”。

未保存时离开页面触发浏览器提醒；提醒文案由浏览器决定。本机备份失败时显示原因状态，并提供“导出草稿”，下载包含当前节点、连接及设置的 JSON。导出不代表服务保存成功，也不打包素材文件。

双击原 `run.bat` 启动，在正式 `http://127.0.0.1:3002/` 刷新普通或智能画布加载新脚本。用户已确认功能成功，按根目录 AGENTS.md 的既有约定，仅同步本项源码、必要测试和本报告。

## 实际改动及旧实现替换

| 文件 | 本项作用 |
| --- | --- |
| `static/js/canvas-save-recovery.js` | 将原仅 sessionStorage 草稿改为 IndexedDB 持久在线备份，保留旧会话草稿兼容；每页独立归属及版本序号；串行写入、原子移交关闭页草稿、恢复互斥；本机失败提示、JSON 导出及离开提醒 |
| `static/js/canvas.js` | 普通画布加载等待草稿准备，再调用已有恢复及冲突合并入口；恢复失败显示提示 |
| `static/js/smart-canvas.js` | 智能画布接入同一准备流程，复用原冲突副本生成与合并逻辑 |
| `static/canvas.html`、`static/smart-canvas.html` | 保存提示增加本机状态及导出按钮，更新相关缓存版本 |
| `static/css/canvas.css`、`static/css/smart-canvas.css` | 沿用各画布主题，适配提示、双按钮、深浅色及窄屏；提示下移避免遮住标题 |
| `skills/canvas-assistant/project-knowledge/index.json` | 同步两入口来源摘要与相关函数行号，不新增能力或改验收状态 |
| `tests/canvas_durable_draft.test.cjs` | 新增 8 项有行为断言的持久草稿回归 |

旧的仅会话存储读写实现已在共享模块原位替换，没有另建产品副本或 v2 入口。旧 sessionStorage 数据作为兼容读取及临时备份保留，不是并行旧业务实现。服务保存确认只清理本页对应草稿；在途追加编辑保留新版本；正在编辑的其他页面草稿不会被领取或清理。
