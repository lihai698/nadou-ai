# 图片结果写盘失败状态修复（2026-10-07）

## 发现与修复

隔离测试复现：图片已经生成成功，最终任务记录写入抛出 `OSError` 时，旧 worker 把写盘异常当作生成异常，尝试执行 `succeeded -> failed`，触发非法状态转换并使后台任务报错。

`main.py::_run_canvas_image_task` 现在分别处理生成异常和成功结果写回。成功结果写盘失败时保留本进程中的 `succeeded` 与结果，只写入不包含敏感内容的诊断；磁盘仍是运行态，重启后继续按 `unknown` 保守处理，不自动重提。HTTP 路径、任务记录格式和供应商协议未改动，也没有调用真实供应商。
