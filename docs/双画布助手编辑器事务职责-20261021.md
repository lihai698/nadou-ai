# 双画布助手编辑器事务职责

`static/js/canvas-assistant-editor.js` 接管两种画布原先位于 `window.onload` 的完整助手适配事务，包括原生编辑器构建、原任务回填、节点工厂、连接与字段写入、助手上下文、模板回调和选中变更。入口只提供实时 host 并调用 `mountClassic` / `mountSmart`。

模块不持有画布副本，不访问存储或供应商配置。画布数据通过 host 的实时 getter / setter 读写；生成、保存、历史、预览和原任务处理继续调用已有公开操作。普通连接校验、循环拒绝、去重和输入同步的先后顺序保持；智能画布连接继续调用 `connectInputNode`。

原生动作的确认、重复执行保护、任务归属和保存门禁仍由 `CanvasAssistantNative` 管理。助手面板、监听器、计时器、取消与重复挂载清理由既有 `CanvasAssistant.mount` / 返回 controller 的 `destroy` 管理；新事务模块不新增事件或计时器，也不另建生命周期副本。

两种 HTML 在画布入口前加载新模块；旧 onload 主体已移除。验收证据保存于 `.git/modularization/canvas-assistant-editor-20261021/`，以其中 `candidate.json` 的树、最终 core / 行为契约 / 浏览器结果为准。该批完成不代表三大文件整体模块化完成。
