# 阶段 10：提示词库可靠写入局部补强

日期：2026-10-04  
范围：`data/prompt_libraries.json` 的读取和保存入口。只使用临时目录与自制提示词，不读取真实提示词库。

## 改动

- `main.py` 的 `load_prompt_libraries`、`save_prompt_libraries` 共用 `PROMPT_LIBRARY_LOCK`，保存改用 `backend.atomic_json.write_json_atomic`。
- 已存在的 JSON 无法读取或不是对象时，读取返回默认库但保留原文件，不再用默认内容覆盖可能可恢复的用户数据。
- 提示词库 JSON 的顶层结构、系统库和既有 API 返回保持兼容；没有新增第二套入口。

## 验证

`tests/test_prompt_library_atomic.py` 3 项通过，覆盖成功读写、替换失败保留旧字节并清理临时文件、损坏文件不被覆盖。测试只使用临时目录和自制中文提示词；`py_compile` 与核心检查由汇合验证统一执行。

## 限制

锁只约束当前进程；不同进程同时修改仍未协调。其他 JSON 直写入口、跨文件事务和正式用户数据恢复仍按阶段 10 清单继续处理，阶段 10 不勾选完成。
