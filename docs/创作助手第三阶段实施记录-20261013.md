# 创作助手第三阶段：逐镜提示词与配图

状态：本地实现和隔离模拟验证已完成主要流程；真实模型效果及用户验收待完成。未提交或上传源码，未调用真实收费供应商。

## 现在的真实流程

分镜表单镜内容 → 素材节点 → 原生 LLM 提示词处理节点 → 原生图片生成节点 → 图片结果。

素材节点保存本镜画面、景别、机位、动作、时长、统一风格及引用的角色/场景/道具。它不负责分析。普通画布使用 LLM 节点，智能画布使用开启 LLM 的原生提示词节点，真正运行后保存本次输入、输出及实际文本模型。图片节点只接收处理结果，用户选择的平台、模型和图片参数保留。

## 使用步骤

1. 使用 `run.bat` 启动；已运行旧后端时先重启，再刷新画布页面。
2. 打开已有分镜表，在创作助手选择文本模型，并选择、确认图片模型。
3. 对助手说：“为这张分镜表的第一镜创建 LLM 提示词处理节点，先只处理这一镜。”
4. 核对所选文本模型，确认运行提示词处理节点；运行完成后继续让助手创建这一镜的配图节点。
5. 核对图片模型、画幅、分辨率及质量，再确认图片运行。也可点击对应原生节点运行按钮。
6. 修改一镜时直接编辑分镜表的对应行，再让助手只处理该镜并创建新的配图节点。明确重做同镜时会新建结果分支，原图保留。

当前采用分步原生确认，不宣称已实现一句话全自动执行整张分镜表。创建节点不等于运行；真实文本调用和图片调用沿用原有确认与预算。

## 单镜修改和复用

- `shotPromptMap` 保存每镜素材节点和处理节点；`generationMap` 增加 `promptProcessorId`，保留对应图片生成及输出编号。
- 表格编辑只同步对应镜头素材。输入或文本模型变化后，旧处理结果不能继续用于该镜图片生成。
- 相同结果和完整图片参数复用现有节点；画幅、分辨率、质量、自定义尺寸变化时仅新建该镜分支。
- 原任务运行中或受理状态未知时，先查询原编号，不新建任务绕过旧状态。
- 复制完整链时重映射节点归属；只复制局部节点时清除无法成立的来源关系。
- 已有逐镜处理链的分镜表不会被第二阶段再次导入直接覆盖。
