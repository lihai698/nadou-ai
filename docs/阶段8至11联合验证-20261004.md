## 代码与数据结果

- `backend/asset_media_rules.py` 接管五个素材类型和文件名规则，旧函数体从 `main.py` 清理。存储文件删除入口会保留画布、对话、历史或素材库仍引用的文件，并在素材管理页报告保留数量。
- 画布标题和图标新增独立修订号，旧快照的完整保存遇冲突返回 409；普通画布列表标题和图标操作改走 `/meta`。打开、软删除、恢复、彻底删除与元数据写入在同一进程的画布锁下串行。
- `history.json` 的三处写入改为原子替换。历史清理失败时，画布日志清理停止删除对应媒体及预览，并返回明确的部分成功提示。
- 图片与 ComfyUI 的后台 worker 共用纯状态流转规则；本地任务仍只保存在进程内，不能据此宣称重启可恢复远端任务。
- 存储目录设置已用原子写入和同进程锁保护；现有 JSON 损坏时拒绝覆盖。旧 Token 接口保留配置回退并拒绝带跨站 Origin 的读取，无法替代完整鉴权。
- ComfyUI 设置页的媒体类型、后端地址清理及字段校验规则已拆入独立脚本，原页面按依赖顺序加载，旧规则函数体已清理。
