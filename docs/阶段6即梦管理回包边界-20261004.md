# 阶段 6：即梦管理接口回包边界（2026-10-04）

## 改动范围

即梦 CLI 的状态、余额、退出登录、登录状态和帮助接口不再把 CLI 原始对象通过 `raw` 字段返回。后端新增 `public_jimeng_credit`，只递归提取常见余额/额度字段的有限数值；退出登录只返回受控短文本，帮助接口继续返回已脱敏、限长的帮助文本。

API 设置页改为读取 `credit` 和 `message` 字段，余额显示、登录状态和帮助弹层的用户操作保持不变。

## 隐私与兼容边界

- 令牌、签名 URL、本机路径、调试字段和非数值余额内容不会进入即梦管理接口响应。
- `credit` 是新的公开摘要字段；旧的 `raw` 字段不再由这些管理入口生成。
- 生成图片/视频的内部 CLI 解析仍只在当前请求内使用，画布生成公开结果继续经过既有压缩入口。

## 验证

- `tests/test_stage6_cli_output.py` 5 项通过，覆盖状态、余额、退出、帮助和登录状态；自制令牌、URL、本机路径均未出现在结果中。
- `python\\python.exe -m py_compile main.py tests/test_stage6_cli_output.py` 通过。
- `node --check static/js/api-settings.js` 通过。

## 恢复方法

恢复 `main.py`、`static/js/api-settings.js` 和 `tests/test_stage6_cli_output.py` 的本次差异即可；没有数据迁移。旧客户端若仍读取 `raw`，余额区会显示为空，应随页面脚本一起更新。
