# 画布上传与拖放职责迁移验收（2026-10-18）

本批承接视频、模型执行和更新协调之后的续接。已迁移普通画布 35 个、智能画布 29 个主体；这里只验收这些职责，三个主文件整体模块化仍未完成。

## 真实入口与职责

| 实现 | 负责内容 | 状态与依赖 |
| --- | --- | --- |
| `canvas-media-drop.js` | 普通画布文件类型、目录递归、拖放文本/路径/URL 解析 | 解析只用参数；上限及浏览器对象由 host 注入 |
| `canvas-upload-coordination.js` | 上传、本地导入、素材/分组创建、节点替换与连线迁移 | 画布仍拥有 nodes、connections、selected；host 实时 getter/setter 读写当前状态 |
| `smart-media-drop.js` | 智能画布文件/目录/拖放与拖放类型判断 | 保留智能画布原有扩展名范围，不合并成不同语义的共用白名单 |
| `smart-upload-coordination.js` | 上传、响应错误、素材追加、本地导入与标题 | nodes、selectedId、undoSuppressed 由编辑器拥有；尺寸与比例保留原行为 |

两类 HTML 在主脚本前加载实际模块；原全局函数保持参数及薄委托，供现有节点、粘贴、文件选择与拖放入口使用。`fillImageNode` 的主体已从普通主文件清理。模块不复制画布状态，不注册新的全局监听器；已有事件绑定仍调用这些真实入口，完整监听生命周期审计尚待后续。
