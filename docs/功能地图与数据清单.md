# 功能地图与数据清单

检查日期：2026-09-30。依据：当前本地源码、路由声明、前端调用和目录元数据；没有读取或公开密钥、提示词正文和私人素材内容。

本阶段为静态结构梳理，不是全部功能实测。接口全集见 [后端接口索引](后端接口索引.md)。代码行号可能变化，应按函数或接口路径检索。

## 1. 入口与关联范围

主入口是 `main.py` 的 `/`，返回 `static/index.html`。侧栏通过 `switchUI` 切换 10 个 iframe 页面。画布列表与具体画布编辑器是不同层级；编辑器分别使用 `canvas.js` 和 `smart-canvas.js`。主题、语言、缩放及 API 配置变更通过共享脚本、浏览器存储和跨页面消息影响多个页面。

| 功能 | 页面/主要实现 | 主要后端入口 | 改动时需回归 |
| --- | --- | --- | --- |
| 导航及全局设置 | index.html；js/theme.js；js/i18n.js | /api/app-info、更新接口、/ws/stats | 页面切换、主题、语言、缩放、嵌入页消息 |
| 文生图 | zimage.html | /generate、/api/generate、/api/history、/api/queue_status | ComfyUI/对应生成方式、历史与结果显示 |
| 细节增强 | enhance.html | /api/upload、/api/generate | 上传、增强和放大步骤、前后对比 |
| 图片编辑 | klein.html | /api/upload、/api/generate、/api/ms/generate | 输入图、模型分支、历史显示 |
| 角度控制 | angle.html | /api/angle/generate、/api/angle/poll_status、/api/generate | 角度参数、轮询、不同服务分支 |
| 在线生图 | online.html | /api/online-image、/api/ai/upload | 配置同步、上传、结果与历史 |
| GPT 对话 | gpt-chat.html | /api/conversations、/api/chat、/api/chat/agent、/api/chat/stream | 会话身份、附件、流式输出、会话持久化 |
| 画布列表/项目 | canvas-list.html；相关画布脚本 | /api/projects、/api/canvases、trash/meta/restore/purge | 项目归属、创建、列表、回收站、编辑器打开 |
| 普通画布 | canvas.html；js/canvas.js；css/canvas.css | 画布保存、日志清理、生成、素材、工作流接口 | 节点、连线、保存、生成、素材引用、导入导出 |
| 智能画布 | smart-canvas.html；js/smart-canvas.js；css/smart-canvas.css | 共享画布接口、canvas-image-tasks、canvas-comfy-tasks、canvas-video、canvas-llm 等 | 独有节点、任务状态、结果、分组与时间线导出 |
| 素材管理 | asset-manager.html；js/asset-manager.js | /api/asset-library、/api/local-assets、/api/prompt-libraries、/api/shared-folders、/api/canvas-assets | 两种画布的素材选择、文件引用、提示词、批量操作 |
| API 设置 | api-settings.html；js/api-settings.js | /api/providers、/api/config、服务商测试/模型查询 | 所有生成页、对话及两种画布 |
| 扩展示例 | backend/extensions.py；backend/local_media_extension.py | /api/extensions、/api/extensions/{id}/run | 只处理显式输入；依赖缺失/停用不影响其他能力 |
| 工作流设置 | comfyui-settings.html；js/comfyui-settings.js | /api/comfyui/instances、/api/workflows | ComfyUI 生成、节点参数映射、导入导出 |

脚本路径均相对 `static/`。本表列出功能入口和代表接口，具体按钮操作需沿接口调用定位，不能把代表接口当作完整调用集合。

## 2. 外部连接与运行状态

| 能力 | 连接位置 | 说明 |
| --- | --- | --- |
| ComfyUI | main.py 的实例配置、上传、工作流与生成函数 | 本地或局域网服务；服务自身保存的文件不一定在本项目内 |
| 通用 AI 服务 | providers、online-image、canvas-video、canvas-llm、chat | 协议与供应商分支较多，测试必须按分支选择 |
| RunningHub | /api/runninghub/* | 工作流、应用、查询及上传，共享模型与服务商配置 |
| ModelScope/角度 | /api/ms/generate、/api/angle/* | 生成及轮询，不在本阶段实际调用 |
| 即梦及其他 CLI | /api/jimeng/*、/api/codex/*、/api/gemini-cli/* | 依赖本机 CLI 和登录状态，登录凭据可能位于项目之外 |
| 外部上传 | /api/temp-sh/upload、/api/cloud-video/upload 等 | 存在对外传输能力，验收使用独立样例并明确范围 |
| 更新/回滚 | /api/update-from-github、/api/update-rollback | 会改写程序文件，二次开发后需评估上游更新覆盖风险 |

`/api/queue_status` 只读内存 `QUEUE`；源码另外有 `asyncio.create_task` 驱动的画布任务，因此“常规队列为零”不能证明所有任务均停止。重启恢复能力需要后续任务专项验证。

## 3. 数据位置、所有权和读写入口

以下路径相对项目根目录；可选配置在功能使用后才创建，未存在不等于丢失。

| 数据 | 位置 | 主要管理入口/函数 | 备份与影响 |
| --- | --- | --- | --- |
| 画布与日志 | data/canvases/*.json | load_canvas、save_canvas、/api/canvases/* | 保存/元信息/日志删除共用；保留节点、连接与素材引用 |
| 项目分组 | data/projects.json | save_projects、/api/projects | 删除项目会改写其下画布归属 |
| 对话 | data/conversations/用户标识/*.json | conversation_path、/api/conversations、chat | 用户标识影响读取；不等于完善的账户认证 |
| 素材库索引 | data/asset_library.json | load_asset_library、save_asset_library、/api/asset-library | 与真实素材文件必须一起备份 |
| 提示词库 | data/prompt_libraries.json | /api/prompt-libraries/* | 两种画布与素材库共同使用 |
| API 服务商 | data/api_providers.json | load_api_providers、save_api_providers、/api/providers | 可能含密钥；加载时会规范化并合并默认配置 |
| 环境配置 | API/.env | 配置加载、生成服务 | 私人备份，不公开上传 |
| 静态服务商及模型 | static/runninghub/api_providers.json、models_registry.json | RunningHub/模型注册与配置逻辑 | 与 data 配置不是同一文件，需分别检查，不能随意合并 |
| 全局配置 | global_config.json（可选） | GLOBAL_CONFIG_FILE 相关读写 | 修改影响跨功能配置 |
| RunningHub 工作流索引 | data/runninghub_workflows.json（可选） | /api/runninghub/workflows/* | 工作流查询、保存与删除 |
| 工作流文件 | workflows/ | /api/workflows/* | 包含内置与自定义工作流，部分名称禁止删除 |
| 原始输入/生成文件 | assets/input、assets/output、output | 上传、生成、下载、历史及画布 | 多个 URL 映射，删除时必须区分输入与输出 |
| 资产库实体文件 | assets/library/ | 素材导入、分类、remove_asset_library_file | 索引与文件可能被不同删除入口影响 |
| 本地素材及伴随说明 | assets/uploads/ | /api/local-assets/* | 删除可能同时移除说明及分类文件 |
| 历史卡片 | history.json | 历史追加、/api/history、/api/history/delete | 历史删除并非一定只删记录 |
| 预览缓存 | data/media_previews/ | /api/media-preview、/api/image-jpeg | 属于派生文件；清理逻辑需与原媒体映射一致 |
| 自定义存储路径 | data/storage_settings.json（可选） | load_storage_settings、apply_storage_settings | 可把输入/输出/本地素材放到项目外，备份需扩展范围 |
| 共享目录配置 | data/shared_folders.json（可选） | /api/shared-folders/* | 外部目录文件不一定随项目备份 |
| 分类提示词 | data/asset_classification_prompt.txt（可选） | /api/asset-classification-prompt | 属于个人自定义内容 |
| 浏览器持久状态 | localStorage | 主题、模型选择、提示词预设/覆盖、最近设置等 | 不包含在项目磁盘备份中；不同端口/浏览器具有不同存储 |
| 浏览器会话状态 | sessionStorage、内存 | 画布视口、尚未保存的编辑等 | 不能假定关闭页面后可恢复 |

本次目录计数：画布 JSON 1 个、对话文件 3 个、预览缓存 15 个、data 根目录 JSON 4 个。只记录数量，不公开私人名称和内容。外部 ComfyUI 数据、CLI 登录状态与浏览器存储不属于阶段 1 已验证的备份范围。

## 4. 删除入口与实际行为差异

| 操作 | 入口 | 已确认的代码行为 | 回归重点 |
| --- | --- | --- | --- |
| 删除画布 | DELETE /api/canvases/{id} | 设置 deleted_at，保存原 JSON | 回收站、恢复、关联列表 |
| 恢复画布 | POST /api/canvases/{id}/restore | 去掉 deleted_at 并保存 | 节点及引用完整 |
| 彻底删除画布 | DELETE /api/canvases/{id}/purge | 删除画布 JSON | 不应解释为同时清理所有素材 |
| 删除项目 | DELETE /api/projects/{id} | 删除项目记录，将画布改归默认项目 | 不删除画布；多文件一致性 |
| 删除画布日志 | POST /api/canvases/{id}/logs/delete | 依据参数只删记录或清理生成媒体、重置结果节点，检查持久化引用 | 旧版本冲突、保留输入、引用判断 |
| 删除历史卡片 | POST /api/history/delete | 写回历史，并仅删除不再被历史、画布、对话或素材库引用的目标图像 | 损坏记录、并发引用与失败回退 |
| 删除素材条目/批量 | /api/asset-library/items/{id}、items/delete | 移除索引并调用 remove_asset_library_file；被其他持久内容引用时保留实体文件 | 共享文件、索引提交与清理顺序 |
| 删除素材分类 | DELETE /api/asset-library/categories/{id} | 先保存索引，再清理不再引用的条目文件；只删除空分类目录 | 共享文件、目录越界与失败回退 |
| 删除整个素材库 | DELETE /api/asset-library/libraries/{id} | 先保存索引，再清理不再引用的图片/工作流文件和空分类目录 | 跨库共享引用与整库删除回归 |
| 删除存储文件 | POST /api/storage-files/delete | 解析路径后检查历史、画布、对话和素材库引用；被引用或记录损坏时保留文件 | 不同 kind、符号链接与失败提示 |
| 删除本地素材 | POST /api/local-assets/delete | 检查主文件及说明/分类伴随文件的引用后，再成组删除 | 画布引用与多文件一致性 |
| 提示词/会话/工作流删除 | 对应 DELETE 或批量 POST 接口 | 各有独立处理流程 | 逐项验收，不用一种删除测试代表全部 |

`iter_canvas_records` 开始时调用 `cleanup_expired_canvas_trash`，按 30 天保留常量删除过期的软删除画布文件，因此列表读取也可能触发清理；超期行为需在阶段 3 的独立样例中验证。以上观察来自代码，没有对用户数据执行删除实验。

## 6. 下一步与使用方法

阶段 3 首批验收样例：两种画布保存重开、节点连线、素材引用、日志删除两种模式、回收站恢复，以及浏览器自定义提示词的存储范围。破坏性操作只使用隔离副本。

每次修改先找到本表的功能行，再查接口索引定位处理函数，检查数据行和删除表确定关联影响，最后据此挑选回归样例。本文件不替代实施前阅读具体代码。

本阶段未修改业务实现、未清理旧代码、未调用生成/上传/删除/更新接口。完整 UI 操作、性能、外部服务与错误场景仍由后续阶段验证。
