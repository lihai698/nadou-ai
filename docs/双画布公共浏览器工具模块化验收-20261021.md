# 双画布公共浏览器工具模块化验收（2026-10-21）

本批将普通与智能画布重复的 HTTP 错误解释和文本复制实现，收敛到 `static/js/canvas-browser-utilities.js` 的六个公共函数。两画布原有函数名、参数默认值和同步/异步属性保持不变，真实入口只委托公共 owner；临时复制监听器、隐藏 textarea、浏览器环境与后备路径仍按原顺序执行。

基线：`1965c22e3523fae6cee88e38378f79043082b755`。固定候选：`7ceac006a63f52bad740f69a1bb4e851f368334d`。本批七个文件与本文单独提交，排除其他聊天仍在开发的工作组、工具栏、素材封面、主题和视口改动。整体三大文件模块化尚未完成。

## 职责与入口

公共 owner 包含 `apiErrorMessage`、`responseErrorMessage`、`copyTextWithCopyEvent`、`copyTextWithTextarea`、`clipboardMatchesText`、`copyTextToClipboard`。两页 HTML 在画布脚本前各加载一次公共模块，并更新对应脚本版本。

两画布分别通过 `canvasBrowserUtilityHost()` 提供实时 `document`、`navigator`、`window` 和原入口回调，保留可替换回调的语义，不捕获另一画布的环境。owner 没有持久状态、定时器、全局监听或存储权限；复制事件只在一次操作期间注册，在 finally 中移除；textarea 在 finally 中删除。没有新增外部依赖或永久兼容实现。

AST 审计覆盖两画布原 12 个完整函数及嵌套回调，迁移为同一组 6 个主体；唯一语法统一是智能画布 `apiErrorMessage` 原有的单条 return 分支与普通画布带花括号分支的写法。移除 host 前缀并统一该单语句 if 的表示后，完整主体一致；原签名和 async 属性一致，其余固定画布 AST 不变。工作区本批入口与候选相同，其他聊天改动继续保留。

## 保留的原有行为与验收输入

Windows 原生 clipboard.writeText 会把本批多行 LF 文本写成 CRLF；原函数的严格读回比较因此返回 false。基线和候选都复现相同系统剪贴板原字节和返回值；复制事件路径保留 LF、单行 textarea 路径正常。该既有行为未作为模块化附带修复。真实浏览器按每次异步复制完成后采集结果，避免误读上一次剪贴板内容；两个版本顺序执行，减少焦点/系统剪贴板竞争。

日志 fixture 只在临时页面中提供自制文本，检查后恢复原日志；无真实私人日志或用户数据。经典画布日志入口在“更多画布操作”菜单内，脚本按实际可见菜单路径点击，不强行点击隐藏按钮。测试默认授予独立浏览器上下文的剪贴板权限；拒绝权限与缺失 API 分支另由独立测试和差分合同验证。

知识索引固定候选仅更新 548 个两画布源码摘要。混合工作区另按当时真实两画布源码计算对应摘要，保留其他聊天的知识文件及其他来源改动。提交使用独立 index 和固定 blob，不暂存混合画布文件全量内容。

没有读取私人配置、真实画布或素材，没有调用真实/收费供应商。使用临时公开代码副本、自制媒体及 loopback；动态插件、真实供应商、私人数据和长期压力不在证明范围内。
