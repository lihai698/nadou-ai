# 清空当前画布接入记录

日期：2026-10-08

## 范围

在普通画布和智能画布左上方的当前画布导航区域增加“清空当前画布”按钮。按钮沿用现有画布的圆角胶囊按钮、主题颜色和 Lucide `trash-2` 图标；普通画布放在标题栏右侧，智能画布放在“返回画布列表”右侧。

清空操作只针对当前画布 ID，保留画布标题、项目归属、图标和视口，清除当前画布的节点、连线、日志与画布设置。执行前显示确认提示。

## 数据清理规则

- 后端入口：`POST /api/canvases/{canvas_id}/clear`。
- 使用客户端保存版本检查并发更新；页面版本过期时返回 409，不执行清理。
- 只解析当前画布节点和日志中的本地生成媒体；输入素材、其他画布和对话不会作为删除目标。
- 生成媒体仍被其他持久化画布、对话或资产库引用时保留，并返回保留文件名。
- 未被引用的生成媒体、媒体预览缓存和 `history.json` 中对应记录会一起清理。
- 清理历史记录或引用核对失败时，画布内容仍会清空，但媒体文件保留，避免误删。
