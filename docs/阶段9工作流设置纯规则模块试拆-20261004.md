# 阶段 9：工作流设置纯规则模块试拆（2026-10-04）

## 职责与入口

`static/comfyui-settings.html` 先加载 `static/js/comfyui-settings-rules.js`，再加载 `static/js/comfyui-settings.js`。实际服务的 `versioned_static_html` 会将两个脚本的 `?v=` 换成各自文件修改时间，因此页面请求新脚本地址。

| 文件 | 职责与数据归属 |
| --- | --- |
| `comfyui-settings-rules.js` | 纯输入规则：推断工作流字段类型、将字段分为提示词/媒体/设置、选择媒体文件类型、清理后端地址、找出第一个缺名称的字段；只接收参数并返回结果。 |
| `comfyui-settings.js` | 拥有工作流、字段值、后端地址和页面状态；负责 DOM、中文/英文提示、API 请求、预览和事件，将当前值传给规则模块。 |
| `comfyui-settings.html` | 页面结构、样式引用、按依赖顺序加载脚本。 |

规则模块不读取页面全局状态、DOM、配置、用户文件或供应商接口，也不反向导入页面脚本。页面脚本的同名旧规则函数体已经删除，不存在两套生效实现。

## 兼容行为

- 工作流布尔、数字、滑块、文本、提示词、图片、视频、音频类型推断及其优先级保持原样；媒体字段仍使用 `image/*`、`video/*`、`audio/*` 文件选择格式。
- 后端地址仍只去掉首尾空白并过滤空项；保留 `host:port`、带 `http://` 的地址和重复项，不在前端新增严格格式限制。
- 保存配置时仍阻止第一个空字段名并显示原有中英文提示。页面状态、接口路径、配置 JSON 字段未变。
- 已保存工作流中的自定义字段名属于内容数据，语言切换时保留原文。
