# 智能输入面板刷新调度验收（2026-10-18）

状态：本批已完成专项、独立审查、真实页面与最终完整核心验证；整体模块化未完成。范围仅为智能画布输入面板刷新调度，不提交、推送、发布或调用收费服务。

## 职责与入口

- 新增`static/js/smart-composer-scheduler.js`，只拥有待执行刷新、生命周期监听和恢复标记；画布、选择、节点、提示词及参数状态仍由原入口持有。
- `scheduleComposerUpdate`变为薄委托，默认120ms及缩略图单击传入的180ms保持。唯一业务调用仍在`smart-node-bindings.js`；该处单击自身的220ms计时器未在本批迁移。
- `updateComposer`只把开头的计时器取消替换为控制器门禁，其余同步展示主体逐语句保持。即时刷新会取消排队刷新；取消后到达的旧回调不能消费新计时器。
- 使用已有媒体输入控制器的画布ID/打开代次检查，加当前选中节点ID核对；同ID重开、跨画布、删除或换选中节点使旧请求失效，正常自动保存替换canvas/node对象仍可读取当前节点。
- `pagehide`取消计时器并阻止隐藏期间的即时更新；`pageshow`仅在存在中断刷新或隐藏期间的更新请求时，按当前选择恢复一次；不重放旧目标。重复挂载不增加监听，`dispose()`解除监听并禁止重挂载。
- 主入口显式注入实时依赖，控制器不反向导入主入口。HTML在主入口之前加载新脚本，挂载顺序在媒体输入控制器之后。无新依赖、样式、持久化格式或外部接口变化。
