# 阶段 9：在线生图尺寸规则试拆（2026-10-04）

## 范围与职责

本次整理在线生图页中与页面状态、DOM 和请求无关的尺寸规则。`static/js/online-image-size-rules.js` 只接收比例、分辨率和自定义宽高，返回规范化尺寸；不读取配置、用户文件、素材、密钥或供应商接口。

| 文件 | 职责 |
| --- | --- |
| `static/js/online-image-size-rules.js` | 保存预设比例、分辨率限制，解析尺寸文本，计算自定义比例和最终尺寸。 |
| `static/online.html` | 页面结构、输入状态、DOM 更新、上传、历史、提交请求和事件；通过 `OnlineImageSizeRules.currentSize` 调用规则。 |
| `tests/online_image_size_rules.test.cjs` | 纯规则结果、边界输入和真实页面入口检查。 |

页面仍保留原来的 `parseSizeValue` 和 `currentSize` 函数名作为页面兼容入口；这两个入口只转调规则模块，旧的尺寸计算实现已删除，没有两套生效逻辑。页面加载规则脚本后才执行内联控制器。

## 兼容行为

- 预设比例、`1k/2k/4k` 尺寸、16 像素对齐、自定义比例像素上限和自定义尺寸取整规则保持原样。
- 无效分辨率仍回退到方形 `1k`，无效自定义比例仍使用对应预设回退逻辑。
- 在线生图接口请求字段、上传、历史卡片、灯箱和中英文页面状态未改变。
