日期：2026-10-21。基线 `9a5aa1bf526a38e9e4087ac465a39a0c44696e99`；固定产品候选树 `e2ccdc29131110617b3fb7b26f4603edac15ea83`。最终树只追加本文。

## 职责与接入

原 `main.py` 的 `_upload_limit_error`、`_base64_payload_size_hint`、`read_httpx_response_limited` 三个完整主体迁入现有 `backend/upload_service.py`，与该模块已有的上传分块读取、Base64 解码落盘职责一致。上传上限仍由应用入口提供，模块不读取配置、凭据或私人文件。

main 保留原函数签名、默认值、仅限关键字参数和异步方式，改为单行委托。新模块显式接收大小上限、分块大小与原错误回调。迁移前后三个完整主体语法树一致，main 与上传模块的其他语法树不变，没有新增模块导入边。原上传接口、Base64 上传和本地素材 URL 导入继续经原入口调用；没有另建测试专用产品入口。

单文件与批次超限的优先顺序、已接受字节对批次累计的影响、Content-Length 预检、无效长度头回退、空分块、读取中断和取消行为均保持原样。读取失败后的临时状态没有被“修正”为另一种语义。

## 验证

- 新增 13 项独立测试；旧树因上传模块缺少目标实现而按预期失败，候选通过。阻断 main、助手和素材索引后，这 13 项测试仍通过。
- 固定树专项基线 889、候选 902，各跳过 2；本批纳入本地素材测试，专项范围与上一批不同。完整 core 通过：Python 1443 项、JavaScript 1180 项，中英文词条检查通过。
- 176 组基线/候选结果精确相等：上传错误、Base64 上界、140 组流式读取与批次状态矩阵、中断/取消，以及 15 次真实 ASGI 上传/导入 HTTP 调用。通过本地 HTTP 服务完成 8 次真实 TCP 请求，观察原素材导入调用远程读取共 6 次，并比较实际落盘文件字节和完整 OpenAPI；比较后未归一业务结果。
- TCP 包含真实 ComfyUI 格式 multipart 上传与远程素材下载。multipart 按实际解析出的字段、文件名、类型、字节与调用顺序比较，未声称随机 multipart 边界的传输原文逐字相同。仅固定测试 UUID，并在原素材元数据读取前固定自制文件的修改时间；实际元数据读取、上传、下载、分块、错误和文件写入均保留。
- 原供应商规则 1288 组（含 28 个完整视频请求体、两个原预期冲突及六组参数 HTTP）、103 组 HTTP/图片查询、29 组火山签名与 19 次本地 TCP 请求、31 组媒体读取/ZIP、46 组助手原生后端对比重新通过。均精确比较。
- 131 个后端模块的顶层和嵌套显式导入无反向 main 依赖或环，上传模块没有后端模块导入边。此项未证明动态插件导入不存在环。
