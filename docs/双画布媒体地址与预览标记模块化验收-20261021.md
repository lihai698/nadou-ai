# 双画布媒体地址与预览标记模块化验收

日期：2026-10-21。基线提交：`3ffee2fe53abb658752e2a1f7363d0eba0b9dc83`；固定产品候选树：`d2368227b1d45837471d461a376439280a2e3a0c`。本批完成不等于原三大文件整体模块化完成。

## 职责与入口

`static/js/canvas-media-sources.js` 接收两种画布各 9 个完整函数，负责媒体原始地址、文件名、代理地址、显示/缩略图地址和图片/视频 HTML。位置、URL 构造器和回调由各画布显式传入；模块没有持久状态、DOM 订阅或定时器。

普通、智能画布原函数名、参数和默认值保留，函数主体只委托新模块。两份真实 HTML 均先加载新模块，再加载更新版本的原主体。原主体的其他 AST 完整一致，HTML 仅改模块加载和入口版本。`main.py`、助手路由和其余后端源码未改。

两画布现有差异原样保留，包括智能画布接受媒体对象及其名称、普通画布支持 flv 缩略图、图片加载属性、视频原生属性，以及非 HTTP 地址直接请求代理时的处理。未借重构统一不同规则。原主函数业务主体已清除，保留的薄适配供大量已有节点、输入、编辑器、素材面板和导出调用方使用。

## 隔离、知识索引和限制

知识索引仅同步已有普通画布 420 处、智能画布 128 处源码摘要，不添加能力或改变验证级别。固定公开 Git 树在临时目录验收，清除凭据环境，使用隔离画布、自制媒体和 loopback；未读取真实私配、用户画布或素材，未调用真实或收费供应商。其他聊天的文档、暂存区和本机脚本保持原样。

并行验收曾因旧辅助脚本共用同名临时 ZIP 而失败；辅助脚本已改为每次独立临时归档，受影响的基线图片刷新和生命周期检查已重新通过。产品候选树不受该脚本修正影响。
