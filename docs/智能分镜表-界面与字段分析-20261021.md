# 智能分镜表

普通画布与智能画布共用 `canvas-storyboard-workbench.js`。真实入口仍为原来的分镜节点；没有额外演示页面。设置默认折叠，主体固定高度滚动，约显示三镜。设置中提供平台、模型、Skill 占位、手动添加及字段勾选。平台与模型来自后台配置，Skill 暂使用内置字段规则。

## 操作

- 创建范围依次支持点选单镜、勾选镜头、全部镜头。点击创建只建原生节点，不执行生成模型；缺少画面或图片提示词时沿用原来的明确提示。
- 每镜一个原生工作组。普通画布保留六节点链，智能画布保留两节点链。重复创建复用已有节点及工作组。
- 双击表格编辑单镜启用字段及镜头时长。确定同步，取消不写入；关闭有改动的编辑面板时提示放弃确认。
- 右键镜头删除，右键自定义列表头重命名或删除；提供一次撤销删除。镜头删除保留已创建节点和素材。内置字段通过取消勾选停用。
- 分析期间禁止重复提交和表内配置修改，错误保留旧表。页面刷新后，视频任务沿用原有持久任务查询；尚未返回的文本规划显示中断，需重新分析。

## 分析范围

勾选只更新保存的 `analysisSettings.enabledFields`，不会调用模型。点击分析才编译启用字段的规则。文本规划从已保存画布的上游提示词/LLM 获取原文，由模型决定镜头数量。视频沿用现有切镜、抽帧及持久任务，使用选定平台和模型；未选择对白时不抽取音轨或转写，只选择对白时不调用视觉模型。

重新分析先确认替换启用字段，未启用字段按镜头顺序保留。保留已有镜头 ID 和生成映射；不覆盖节点中独立修改过的提示词。文本源在模型返回后重新校验，源文已改时不应用旧结果。未配置的外部 Skill 不会假装执行。

后端新增 `canvas_storyboard_analysis.py` 与 `/api/canvas-video-deconstruction/storyboard/analyze`。主入口增加文本/图片来源校验及视频上游参考读取。修改 Python 后需重启现有主程序，刷新浏览器不足以加载接口。

## 上游同步与删除按钮修正

普通画布恢复悬浮节点才显示垃圾桶、悬浮按钮浅红高亮的行为；智能画布原有删除样式不变。分镜表工具栏下方加入紧凑的上游输入区，两种画布共用布局，图片/视频调用各自原生缩略图函数，文本安全显示。输入从当前连线读取，提示词编辑沿用现有更新入口刷新，不在分镜表内另存素材副本。

后端从保存后的画布读取上游文本和图片，LLM 使用输出，未运行或失效的输出不冒充结果；断开连线后不再读取旧绑定文本。纯图片及文本配图片可规划分镜；视频分析携带上游文本和参考图片，参考图片与采样帧明确区分。模型返回前检查素材变化。当前每次支持一个上游视频、最多 32 张参考图片；音频可展示，需先用既有音频节点转写为文本后参与分析。本轮自动验证使用模拟模型，未调用真实供应商。

## 验证边界

设置图标右侧的箭头可收起分镜表。收起后为 320×160 的摘要节点，显示名称、镜头数量、启用字段数量及分析状态；卡片可拖动，连线端口随尺寸更新。折叠状态和原始尺寸随节点保存，展开恢复原始宽高；不改变分镜数据、分析配置或任务。折叠时隐藏缩放手柄，需展开后调整表格尺寸。点击折叠卡片的设置图标会展开并打开设置区。

相关 JavaScript、Python 单元测试及双画布隔离浏览器操作验证通过。浏览器验证涵盖滚动、选中高亮、设置、字段勾选不发分析请求、草稿取消与确认、删除撤销、模拟分析回填、逐镜分组、重复创建、保存重开和深浅主题。测试画布及接口均隔离，未调用收费供应商、未改用户画布；真实供应商效果仍需用户选好模型后验证。

当前工作区含其他窗口的改动。未提交本功能，后续仅在用户确认成功后精确提交相关改动；尤其不要把整个 `main.py`、HTML 缓存版本或无关运行时模块整体混入提交。
