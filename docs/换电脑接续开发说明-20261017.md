## 安装、启动与基础验证

先读 `docs/安装启动说明.md`，但其中固定端口和旧提交状态是历史说明。当前 `run.bat` 会检查环境和端口，按 `NADOU_PORT` 等实际配置处理已有服务；以启动输出地址为准，新环境通常使用 3000。不要把旧电脑的自定义端口当成所有电脑默认值。

源码环境可使用虚拟环境安装锁定依赖；在项目根目录执行：

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
```

之后可将本终端 PATH 指向虚拟环境，再启动项目；此设置只影响当前终端：

```powershell
$env:PATH = (Join-Path (Get-Location).Path '.venv\Scripts') + ';' + $env:PATH
python --version
node --version
.\run.bat
```

`run.bat` 如果发现项目内 `python\python.exe` 会优先使用它。先核对实际解释器与依赖，不要以为虚拟环境必然被该脚本使用；源码包是否带齐离线运行时应实际检查。视频导出、语音及视频拆解还要核对 FFmpeg/ffprobe。

在已安装完整依赖的解释器下运行：

```powershell
python tools/check-core.py
python tools/prepare-release.py --preflight
git diff --check
```

解压包没有 Git 时跳过最后一条，使用文件清单核对。检查通过后实际打开普通画布和智能画布，确认中文、图片、按钮、保存重开、历史和任务状态。不要未经配置就发起真实收费生成。
