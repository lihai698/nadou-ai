# 阶段 9：素材管理文件列表控制器试拆（2026-10-04）

## 范围

本次整理只覆盖 `static/asset-manager.html` 偏好设置中的“素材管理”文件列表。图片资产、工作流、提示词、画布资产和本地素材的业务逻辑保持在原页面入口中。

## 职责边界

- `static/js/asset-manager-storage-files.js` 负责列表请求会话、目录切换、分页、选择集合和滚动位置恢复。
- `static/js/asset-manager.js` 负责弹窗结构、目录设置表单、删除 API、状态提示及页面事件路由。
- 控制器通过 `loadPage(kind, offset, limit)` 和 `onChange()` 注入请求及渲染，不依赖页面的 API 实现和 DOM 结构。

控制器为每次打开弹窗和每次请求分配会话令牌。快速切换目录、关闭后重开或旧请求报错时，过期响应不会覆盖当前目录，也不会把旧错误显示到新弹窗。分页追加保留已选项和滚动位置，切换目录会清空旧选择。

## 入口与清理

`static/asset-manager.html` 先加载控制器，再加载唯一的 `asset-manager.js` 页面入口。页面入口中原来直接维护的文件列表请求、分页字段和选择集合已经删除，没有第二套列表控制器。
