## 完整职责归属

| 现有模块 | 本批接管的职责 |
| --- | --- |
| `provider_protocols` | 21 个规则：视觉模型识别、默认聊天模型、图片请求模式、各平台/模型族识别及素材认证平台分发 |
| `video_request_service` | 13 个规则：火山媒体 role、时长、分辨率、Seedance2、可信素材编号、APIMart/VEO3.1 模型/时长/比例/分辨率及视频提示词 |
| `provider_media_transfer` | 两个视频引用 URL 格式校验，保留通用与 APIMart 对 data URL 的区别 |
| `image_size_rules` | ModelScope 尺寸归一与原 400 错误 |
| `video_provider_service` | 按原协议与默认地址解析视频 API 根路径 |

38 个完整函数主体（包括内部生成器与推导式）迁移后语法树一致；main 原签名/默认值保持，只有单行委托。main 增加现有 provider_protocols 模块导入，其他 main 与五个模块的既有语法树不变。模块内部省去 main 返回类型别名；这不改变原公共入口签名。

本批只处理传入值的规则，不获取配置、凭据、文件、锁或网络。跨规则判断与默认模型等依赖显式传入；main 继续连接当前配置和原回调，所以原测试注入仍生效。真实图片/视频分发、参数接口、请求体构造、素材注册、任务刷新继续经过这些原入口，没有建立脱离应用的新路径。精确函数表、基线/候选引用与全嵌套定位清单保存在证据目录。
