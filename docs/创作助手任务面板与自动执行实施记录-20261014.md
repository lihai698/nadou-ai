# 创作助手任务面板与自动执行

日期：2026-10-14。状态：本地实现及隔离验收通过，等待用户实际使用确认；未提交、未上传。

## 这次解决什么

普通画布与智能画布使用同一个创作助手处理逻辑。聊天区用于交流和成果，执行过程、计划、授权、错误和原生方案移到画布名称右侧的“任务”入口。点击后打开独立面板；确认成功后收起，不占用聊天消息位置。完成记录仍能打开查看。

本次替换的是共享助手原有的任务卡聊天展示入口，没有创建另一个助手副本；原生节点、真实 API、任务查询和保存入口继续使用现有实现。旧第四阶段紧凑状态样式保留，展示位置由本次任务面板接替。

## 自动执行范围

1. 普通创建、更新、连接、分镜编辑等安全动作自动执行。
2. 模型节点运行首次需要用户确认本轮的明确模型及累计节点运行上限，点击“授权并继续”后，范围内自动执行、保存并继续完成目标。
3. 上限默认显示 10，用户可改为 1–100。授权只对当前回合有效，记录已预留次数并持久保存；重复确认同一动作不重复预留。失败预留不退回，避免不明确受理时重复消耗。
4. 这个上限计算节点服务调用，不包含创作助手规划对话，不代表金额上限。
5. 超过次数、使用未覆盖模型、删除、导出及必要创作决定仍在任务面板处理。复杂智能循环的逐槽模型授权尚未扩展，保持原确认方式。
6. 失败和受理状态未知不会自动重提收费任务。原任务有编号时可以查询，停止本轮会阻止后续提交，已受理任务保留。

## 怎么使用

1. 使用原启动入口 `run.bat`，打开普通或智能画布的“创作助手”。
2. 在“模型”里明确选择并勾选文本模型；需要配图时同时选择并勾选图片模型。
3. 正常输入创作需求。普通编辑自动推进，需要决定时“任务”显示“待确认”。
4. 打开“任务”，展开“授权本轮自动执行”，核对模型和节点调用上限，点“授权并继续”。
5. 范围内连续工作，完成后聊天区交付成果。“任务”可查看处理记录；运行中可点“停止本轮”。

## 关键实现

- `static/js/canvas-assistant.js`：共享任务面板、自动推进、失败停止、聊天与任务分区。
- `static/css/canvas-assistant.css`：复用原生助手风格的任务入口和独立面板。
- `backend/canvas_assistant_autonomy.py`：安全动作、模型范围和累计调用预留。
- `backend/canvas_assistant.py`：真实授权接口及原生、图片任务的后台校验。
- `backend/canvas_assistant_agent.py` 和项目知识：统一本轮授权和实质成果回复规则。
- `backend/canvas_assistant_operations.py`：快照散列把 `1.0` 与 `1` 视作等值，修复浏览器保存造成的误拦截；真实数值、正文或参数变化仍失效。
- `backend/canvas_assistant_shot_prompts.py`：智能素材模型和图片默认字段对齐原生保存格式，防止第一次渲染让刚提出的方案失配。
- 两种画布 HTML：更新共享助手资源版本。
