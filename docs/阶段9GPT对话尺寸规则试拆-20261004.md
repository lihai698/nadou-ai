# 阶段 9：GPT 对话尺寸规则试拆（2026-10-04）

## 范围

本次整理 GPT 对话页中与页面状态、DOM 和请求无关的尺寸规则。普通画布、智能画布、对话记录、附件上传和供应商请求均不在本次范围内。

## 职责与依赖

| 文件 | 职责与数据归属 |
| --- | --- |
| `static/js/gpt-chat-resolution-rules.js` | 保存 GPT 对话页的比例/分辨率预设；规范化自定义尺寸；根据提示词解析尺寸和比例；根据提示词与尺寸推断请求分辨率。只接收参数并返回结果，不读取 DOM、localStorage、配置、用户文件或网络。 |
| `static/gpt-chat.html` | 持有当前模式、比例、分辨率和自定义尺寸状态；负责页面 DOM、语言提示、弹层、localStorage、对话接口和事件。通过规则模块兼容入口取得尺寸结果。 |
| `tests/gpt_chat_resolution_rules.test.cjs` | 纯规则、提示词边界和真实 HTML 脚本入口的 Node 隔离测试。 |

规则模块只依赖 JavaScript 标准对象和正则表达式；页面入口依赖模块公开的 `SIZE_OPTIONS`、`CHAT_RATIO_VALUES`、`VALID_RESOLUTIONS` 及四个规则函数。模块不反向导入页面脚本，也不拥有对话状态或请求参数。

## 兼容行为

- 保留原有 1:1、2:3、3:2、3:4、4:3、9:16、16:9 预设和 1K/2K/4K 尺寸。
- 保留 `x`、`X`、`×`、`*` 尺寸分隔符、中文“比”比例写法和中文高清/超清提示词。
- 保留自定义尺寸 256-8192 的边界、无效值回退 `1024x1024`、自定义分辨率下没有明确比例时保留当前尺寸，以及根据请求尺寸推断 `1k/2k/4k` 的原有规则。
- 页面继续保留 `normalizeChatCustomSize`、`chatSizeForResolution`、`chatResolutionForRequest` 和 `chatSizeFromPrompt` 入口名；这些入口只转调规则模块，旧的正则和尺寸计算实现已删除。
