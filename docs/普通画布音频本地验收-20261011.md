# 普通画布音频本地验收（2026-10-11）

依据用户“开始吧”，继续补齐6项音频本地验收。使用当前公开源码的独立副本、端口3048、自制6秒440Hz WAV、缺失文件、伪WAV和独立画布。助手文本模型与原识别结果模拟；画布、上传、保存、素材库、助手工具、确认和原任务读取使用现有真实入口。正式3002及私人配置、素材、任务记录未操作。

## 发现的问题与修复

1. 空音频节点“拖入或点击上传音频”没有接入文件选择器，实际点击无响应。现在复用`pickMediaForNode → fillImageNode → /api/ai/upload`，音频节点只允许单个音频文件。即使文件选择器被绕过，也在上传前拒绝图片等非音频内容，保留原素材。取消选择保持原状态，上传失败有明确提示。
2. 普通音频下载使用直接下载链接，HTTP失败不会向音频卡回传错误。现在沿用原`/api/download-output`代理及`downloadBlob`，先核对请求成功和文件非空，再下载；失败显示音频素材错误提示。

产品修改仅`static/js/canvas-audio-host.js`的上传/下载适配，`static/js/canvas.js`的原文件选择器和音频类型保护，以及`static/canvas.html`这两个脚本的缓存版本。旧的未接入上传适配和无错误回传下载分支已就地替换，没有新增另一套产品入口。其它窗口布局、节点移除和CLI改动未纳入本轮范围。
