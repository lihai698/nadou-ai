# 助手节点公共规则模块化验收（2026-10-21）

本批将创建节点及原任务忙碌保护归入 `backend/canvas_assistant_node_rules.py`，消除故事、故事分析、逐镜提示词、图片提议和状态读取对操作编排器的反向依赖。整体模块化仍未完成。

## 职责与依赖

- 公共规则拥有 `StrictOperation`、`CreateNode`、`new_node`、`audio_task_active`、`is_busy` 的唯一实现；只处理调用方传入的数据，仅依赖标准库、FastAPI 异常和 Pydantic 校验，不读配置、文件、网络或主入口。
- `canvas_assistant_operations` 继续负责计划校验、操作编排、连线规则及候选文档构造，使用导入的公共模型和函数，无旧实现或转发包装。
- generation、story、shot_prompts、state、native、loop 的实际调用均迁移公共规则。故事分析仍沿用故事领域接口。native/loop 仍需操作层的摘要、设置和连线规则；本批不声称消除助手系统所有依赖。
- 持锁写入、版本校验、供应商执行及前端事件归属保持原职责。智能提示词前端迁移后置，本批未修改双画布 JS 或 main.py。
- 知识索引只更新本批来源摘要，将音频任务判定证据迁到公共规则模块，不刷新其他窗口的源码摘要。
