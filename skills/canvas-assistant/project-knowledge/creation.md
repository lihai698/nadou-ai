# 创作方法与质量核验

## overview

先确认成品要求，读取节点规则和实际素材，再规划组合、执行可用工具并核对作品。

## controls

使用现有三项Skill目录，手选Skill优先；它们不会扩大工具权限。复杂任务先拆清文本、参考素材、各阶段产物及依赖。明确主题/受众/构图/风格/镜头/角色一致性及禁用元素；按原生模型能力确定参考和尺寸。每阶段检查真实结果，最终按用户要求检查中文文字、人物一致性、画面构图、素材来源和视频时序。inspect_result送入真实图片后才可声称看过，任务成功不能代替作品质量。无图或模型无视觉时明确未验证；付费图片方案等用户点击生成，不擅自重试。

## parameters

inspect_result 可核对本画布真实图片和视频素材编号。图片按本地完整文件、原任务和确认要求核对；视频只支持可独立读取的本地MP4/MOV、WebM/MKV、AVI，读取真实尺寸、时长、是否有音轨，并提取最多三张带实际时间戳的关键帧。视频抽帧不能证明全片连续性和音频内容；未提供可信作品要求时整体结论为无法判断。只有所选文本模型确实收到本次图片/关键帧，才能登记可见语义评价；文件、任务或画布变化后必须重读，不接受旧评价。检查失败不自动重生或重提收费任务。

模型由用户手选，工具预算与确认边界来自AGENT_GUIDE；目录与能力状态不等于已执行。
多步任务通过create_plan保存目标、保留内容、要求和步骤依赖，再通过execute_plan_step执行一个已开放工具。程序核对真实保存回执后才完成步骤；最终步骤完成无需额外模型调用。累计模型/工具/活动时间预算不因续行重置，新生成服务默认额度为0；已有原任务的查询/取消保留原编号，不作为新生成次数。主动停止不自动续行；断线时先恢复真实写入回执或原任务，不重放已执行步骤。
循环专用字段和剪辑编辑先通过原生动作能力合同核对。智能循环values数组保留每个字段的内部换行和空字段；variablePrompt是兼容正文。剪辑移除走原生remove，保留excludedSources，防止上游同步将已移除素材重新导入。原生方案等待确认；看到方案卡不等于已完成，只有保存后核验的回执能作为下一步依据。

## limitations

持久计划、图片硬条件、已确认原生视频任务硬条件和有限视频关键帧检查已接入现有助手历史。本轮 native video run 的 proposalId 绑定原编号、画布/动作/输入/手选模型和原输出保存；不能从当前节点参数或模型描述伪造确认要求。全节点动作覆盖、视频全片连续性和音频语义仍待继续验收，真实模型效果按授权单列。当前计划默认服务额度为0，用户可在计划卡设置累计服务任务上限，不能以计划或模型文字越过生成确认及额度边界。
