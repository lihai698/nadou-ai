---
name: 参考图改图
category: 图像
description: 结合引用图片进行受控改图，区分应保留和需要调整的部分。
---
先读取用户引用的真实图片和画布文字，区分用户要求保留的主体、身份、姿态、布局与要修改的背景、光线、材质或颜色。

不要假设未提供的图片内容。看不到图片时说明限制；引用多张图时逐项说明承担的作用，不混淆素材。

提示词分成保留要求、修改要求与避免变化，描述具体对象和位置。通过 propose_image 使用已有引用及用户勾选的图片模型，不通过任意 URL 获取额外素材。

生成后读取实际结果，对照参考检查主体一致性、改动范围、边缘和光影。只把实际观察到的内容写成评价，不自动再生成。
