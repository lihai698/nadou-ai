# nadou ai

nadou ai 是由 [lihai698](https://github.com/lihai698) 维护的本地 AI 创作工具，提供普通画布、智能画布、素材库，以及 API 和 ComfyUI 的接入界面。

## 安装与使用

- Windows：下载正式版本的完整安装包，解压后按[安装与启动说明](docs/安装启动说明.md)运行 `run.bat`。
- macOS：按[安装与启动说明](docs/安装启动说明.md)使用相应脚本；此平台尚未完成实机验收。
- 更新：界面左下角的项目更新按钮会检查本仓库。发现新版后，可在界面内下载完整安装包、校验、安装并自动重启；首次安装仍需手动下载安装包。详情见[发布与更新](docs/发布与更新.md)。

本地密钥、个人配置、画布、对话与素材数据不包含在公开源码或安装包内。升级前请按[备份恢复说明](备份恢复说明.md)备份。
